### 4.2 全负档：SE=0 镜像病灶 + 收缩方向偏置

E0 的回退链为 cell（n≥100）→ parent → per-action 基准；**基准层不收缩（p̂=k/n），cell/parent 层向共享 per-action 经验基准收缩 m=100**。两个机制叠加：

- **动作级全负（aal）对基准率全平（0.465–0.466）**：全部行皆负 → 共享基准 p_win=0 → 收缩不产生上偏；损失侧 Wald 上界（p̂_loss≈0.85 + z·SE）提供少量保守裕度 → 覆盖未塌向 50% 而停在 0.466（x0.0 纯形 0.814）。残余欠覆盖来自 r 的不确定度未传播（r̂ 抽样波动使 EV_lb 与 EV_true 的比较近似掷硬币）。
- **父格全负（pal）随基准率单调恶化（b0→b1：0.466→0.057）**：S2 侧混合档的胜行**污染共享 per-action 基准** → 损角格的 p̂_win 被系统性拉高 → EV_lb 高于 EV_true（下界裕度 −0.293，全部结构最差）。b=1.0 时最极端：基准几乎全胜，损角估计被大幅上抬。
- **n 越大越糟**（pal：n1 0.424 → n100 0.139；aal 同向 0.561→0.401）：行数增大使 SE→0 而收缩偏置不缩小，偏置主导。

全胜侧是它的镜像：收缩把 p̂ 从 1 拉低（保守方向）→ 覆盖高（paw 0.931）；纯 SE=0 路径（aal 的 p̂≡0、aaw 的 p̂≡1）下 EV_lb 退化成点估计与 r̂ 的函数 → aaw x0.0 精确 0.49–0.51。

### 4.3 同日簇：有效样本膨胀

行数 = 日数 × 簇大小，而同日簇共享当日单一结局（信息量=日数）。估计器按行数计 SE → 簇越大 SE 越被低估 → 覆盖单调下降（0.670→0.602→0.560）、红牌单调上升（196→237→275）。典型：n100|parent_all_loss|b1.0|c10 的 S1|A1|f0 格有 520 行但只有 100 个独立日（§7 案例 1）。

### 4.4 混合档：收缩偏置主导

混合大 n 覆盖 0.617–0.618，远低于锚 2 预期的 >95%。机制：收缩目标（共享 per-action 经验基准）相对每格真值有系统性偏离——Dirichlet(40·均值) 的格间异质性使 sd(p_win)≈0.07，而 z=1 × 原始 n 的 SE≈0.05（n≈100 行），偏置量级 > SE 补偿量级。**四估计器一致（0.61–0.63）**，说明欠覆盖由点估计偏移（向共享基准收缩）主导，不是 SE 公式选择问题；E0 的原始 n Wald SE 偏大只提供了部分补偿（§5）。

### 4.5 K 跨界 time 化：双向失真，红牌数下降是假象

x0.5 把 50% 行的结局改计为 time（估计器可见），真值不变。后果按结构两极分化：

| 结构 | x0.0 覆盖 | x0.5 覆盖 | 机制 |
|---|---|---|---|
| action_all_loss | 0.814 | 0.118 | 观测损失被稀释（0.85→约 0.45）→ EV 估计上抬 → EV_lb 远高于 EV_true（覆盖塌） |
| parent_all_loss | 0.415 | 0.090 | 同上 + 基准污染 |
| mixed | 0.721 | 0.598 | 同向较弱 |
| action_all_win | 0.501 | 0.987 | 观测胜率被稀释 → EV 估计下压（保守方向）→ 覆盖升 |
| parent_all_win | 0.867 | 0.995 | 同上 |

红牌总数 x0.5（313）少于 x0.0（395）**完全由胜档覆盖改善贡献**（verdict_c RED 309 vs 387）；与此同时**开放率上升**（0.205→0.224）、误开放均值上升（3.25%→5.06%）、误开放红牌增多（27→42，verdict_f）。即：time 化不是"压低 EV 降低开放"，而是让损档估计变得乐观——既塌覆盖又增加误开放。（此为对协调者初判的修正，以重算数据为准。）

## 8. 结论与版本化估计器变更提案（提案，不实施）

**结论**：

1. 现行 P2 估计器（E0 形态）的"EV 下界保守"声明在合成矩阵上**不成立**：覆盖红 696/1200，全局覆盖 0.611（名义 84%、门 95% 双未达）。
2. 病灶排序：**收缩方向偏置（向共享经验基准，损角被上抬、混合档被拉离真值）> 有效样本口径（行数≠日数，SE 被簇膨胀低估）> 边界格 SE=0（p̂≡0/1 退化）> r 不确定度未传播**。误开放不是主因（红 69 vs 覆盖红 696），但其热点（混合小 n + 簇 10 + 内部基准率）与覆盖弱点同带。
3. 区间式替代（E1–E3）不能修复：欠覆盖档更差、误开放翻倍；仅在胜角 SE=0 病灶上局部更好。
4. 大 n 不救覆盖（混合 n100 0.618、pal n100 0.139）——问题不在样本量，在估计器口径。

**版本化估计器变更提案（候选方向；按预注册义务，须经下一批预注册验证后才可实施，阈值 lb_z=1.0 / 2×成本 / min_cell=100 / m=100 一律不动）**：

1. **有效样本量按日/簇去膨胀**：Wald SE 的 n 改用独立日数（n_eff=日数），或按簇结构折算设计效应。证据：簇维度覆盖 0.670/0.602/0.560 单调降（§4.3）；与单位纪律条款（"重复行不得伪增 n"）一致——现行估计器违反了研究侧早已成文的原则。
2. **边界格（k=0 或 k=n）的 SE 规则化**：如 Agresti 式加 2 成功 2 失败后再计 Wald SE，或直接采用 E2（Clopper-Pearson）但以有效计数（提案 1 的 n_eff）。证据：SE=0 角点覆盖退化为 r̂ 驱动的掷硬币（aaw x0.0 全格 0.49–0.51）；E2 在胜角 0.881 表明区间式在角点可行，但必须先解决其损角点估计上偏（配合提案 1/3，单独替换会恶化）。
3. **r 的不确定度传播缺失披露（最低义务）**：r̂ 抽样波动不进入 EV_lb 是覆盖天花板的一部分（案例 1/3 的残余欠覆盖）；若短期不实施传播，必须在方法档案与轮次草案中显式披露为已知局限。

附带披露项（下一批预注册设计需覆盖）：**共享 per-action 经验基准的污染路径**（pal 随 b 恶化至 0.057）说明收缩目标本身携带跨局面信息泄漏，上述 1–3 不单独解决它；候选处理（如按局面分基准或收缩强度分级）留待下一批预注册设计评审。
