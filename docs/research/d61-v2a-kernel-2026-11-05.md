# D61 V2-A 纯内存计算核（2026-11-05）

这是隔离工程实现及固定人工验收说明，不是统计研究结果或产品替换。规格依据为[归档设计 §2/3.1/9](d61-estimator-v2-validation-design-2026-11-03.md)及主会话 `demo-next-20261105` 工作树内 `docs/reviews/2026-11-05-d61-v2a-scope-review.md` 的三项实施前裁定。基点为 `c0df5a1d133eadbe8a8c089fba0758ed840d830b`。

## 接口与输入

只从 `mt5quant.prob.d61_v2a` 直接导入，不增加包级导出。

```python
from mt5quant.prob.d61_v2a import PlanRow, estimate_v2a

rows = [PlanRow(d, "S1", "A2", "f0", "win", 1.9) for d in range(800)]
result = estimate_v2a(
    rows,
    query=("S1", "A2", "f0"),
    support={"win": (0, 4), "loss": (-2, 0), "time": (-1, 1)},
    lb_z=1.0,
)
```

`PlanRow(day_id, situation, action, feature, outcome, gross_r)` 是 frozen dataclass。`rows` 必须为记录序列，生成器不属于此接口。`day_id` 为非负 builtin int（非 bool）；行局面为 S1/S2、动作为 A1/A2、特征为 f0/f1/na。行枚举允许 S2:A1，但查询白名单严格为 S1:A1、S1:A2、S2:A2 × 三特征。查询接受三项 tuple/list。相同 `(situation, action, day_id)` 的特征冲突拒绝。

缺失必须同时满足 `outcome is None` 和 `gross_r is None`；否则结局为 win/loss/time，收益为有限 builtin int/float。结局是显式类别，不从收益正负推断。支持映射键恰为三种结局，各值为两个端点的 tuple/list，严格 `a_o < b_o`；可见收益必须在对应闭区间。bool、其他数字类型、非有限值、越界值均以 `ValueError` 拒绝，不裁剪输入或更改支持。查询无样本也完整验证所有行和支持。

整数直接解释为精确 Fraction，float 使用其精确 binary64 有理值。全局 `a=min(a_o)` 必须能精确表示为有限 binary64；`±(2**53+1)` 作全局 a 拒绝，`2**100` 允许。其他端点不增加该精确性限制，甚至端点或支持宽度超出 binary64 范围，只要最终输出均能有限表示仍可计算。不能产生有限输出则拒绝。`lb_z` 只接受 builtin 1 或 1.0；无 m、资格日数、delta 或精度调参入口。

## 返回值

`V2AResult` 与嵌套的 `LayerCounts` 均为 frozen dataclasses。

| 字段 | 含义 |
|---|---|
| `lower`, `guard` | 候选下界及目标保护界，向下舍入的有限 float |
| `radius` | 目标半径上包围，向上舍入；零目标日为 None |
| `mean_w` | 缺失填 a 后的目标日等权均值；零目标日为 None |
| `center` | 所选层的精确收缩中心转 float；无可见中心为 None |
| `selected_layer` | cell / parent / action / none |
| `target_days` | 目标显式计划日数 D，不加伪样本 |
| `cell`, `parent`, `action` | 每层 `row_count`, `planned_days`, `visible_days`, `outcome_counts`, `missing_count` |
| `p`, `r` | 所选层概率与条件收益三元组 |
| `q`, `v` | 动作池的日等权结局比例与收益贡献三元组 |

所有三元组采用 win/loss/time 顺序；原始计数为 int，其余数值诊断为 float 或 None。`outcome_counts` 为原始可见行计数，`missing_count` 为缺失行数。无可见池时 p/r/q/v 均为三个 None。已知零概率返回 0.0；条件收益实际分母为零时返回 None，其 EV 贡献为零。局部未出现、但动作池存在的类别可有已知收缩条件收益。显示用 float 不回流计算。不返回研究 PASS、批准、模型或交易信号。

## 统计及数值约定

每层先选行再按全局 day_id 聚合。动作池仅含同动作，跨局面同日先合并平均，不先平均父格，也不把 `(parent, day)` 当独立日。目标 W 以每条缺失行填 a，以该日全部计划行数为分母，再日等权平均。中心 Y/Z 仅使用可见行，所有结局共用该日可见行数作分母；全缺失日不进入可见资格日数。只数显式日，不补 ID 间隙。

cell/parent 各须达到 100 个可见日；否则回退到有可见行的动作池，再否则 none。令 `k=sum Y`、`s=sum Z`、`q=mean_pool Y`、`v=mean_pool Z`，cell/parent 使用 `p=(k+100q)/(D_visible+100)`、`r=(s+100v)/(k+100q)`，中心为 `(sum s+100 sum v)/(D_visible+100)`；action 自身使用 `sum v`。固定 m=100 仅改变中心，不增加目标 D。

固定 `delta_c=1/900`、`lb_z=1`。目标 D>0 时计算

```text
h = (b-a) sqrt(ln(900)/(2D))
guard = max(a, mean_w - h_up)
lower = max(a, center - abs(center-mean_w) - h_up)
```

无中心时 lower=a，但 D>0 的 radius/guard 仍计算。D=0 时 lower=guard=a、mean_w=radius=None，中心可保留池诊断。

每次半径调用创建完整私有 Decimal Context：prec=80、Emin=-999999、Emax=999999、clamp=0、capitals=1、空 flags；除正常 Inexact/Rounded 外的信号均显式设 trap，不继承当前或 DefaultContext。ln/sqrt 用 HALF_EVEN，紧接同一 context 的 next_plus；精确整数构造 Decimal，Fraction 商用 ROUND_CEILING：

```text
ell_up = next_plus(ln(Decimal(900)))
q = Fraction(ell_up)/(2D)
t = ROUND_CEILING_80(Decimal(q.numerator)/Decimal(q.denominator))
s_up = next_plus(sqrt(t))
h_up = Fraction(s_up)*(b-a)
```

数值异常转换为 ValueError。后续公式全用 Fraction。lower/guard 向下、radius 向上转 float，比较候选 float 的精确 Fraction，必要时只 nextafter 一次，并重新验证方向和有限性。不用 math.log，不根据结果重试精度。精确 a 与 `center-abs(center-mean_w)<=mean_w` 保持 `a<=lower<=guard`，且返回下界不高于理想公式。

## 固定人工验收

实际调用采用支持 win[0,4] / loss[-2,0] / time[-1,1]，结果保存于工作树 `.superpowers/sdd/2026-11-05-d61-v2a-kernel/fixed-samples.json`。

| 样例 | 实际结果 |
|---|---|
| 日0 S1 win/4、S2 两条 loss/-2；日1 S1 win/2 | 动作池2日、center=1；q=(2/3,1/3,0)，v=(5/3,-2/3,0) 的 float 诊断；r=(2.5,-2,None) |
| 目标日0 win/4+missing，日1 missing | D=2、visible_days=1、mean_w=-0.5、center=4 |
| f0/f1 各800日、全胜1.90 | 两格 radius=0.39122101448515906，lower=guard=1.5087789855148408 ≥0.10 |
| 同池空 na | D=0、lower=guard=-2，radius=mean_w=None，center=1.9 |
| 800日合法 loss/-1 负控制 | lower=-1.3912210144851591 <0.10 |
| 临近门槛收益 0.491221014485159 / 0.49122101448515904 | lower 分别为 0.09999999999999996 / 0.10000000000000002，不加 epsilon |

独立 oracle 使用 `ln900=8ln2+2ln(15/8)`。对 `z=(x-1)/(x+1)`，取120项正项有理级数 `2 sum z^(2k+1)/(2k+1)`，余项严格不超过 `2 z^(241)/(241(1-z²))`。平方根通过整数 isqrt 在420位二进制定点网格包围，并精确平方复核。它不使用被测半径生成期待值，也不以两种 Decimal 精度比较冒充误差界；测试另将实现的精确 h_up 及最终 radius 与此有理包围比较，并认证最终 lower/guard 不高于理想下界的下端。

验收还覆盖99/100两层资格、三类共同可见分母、池有而局部无类别、全缺失、目标空、其他动作排除、全局日整组1/3/10倍复制和确定排列逐位一致、污染池不改变 W/D/radius/guard、正负次正规数、超大精确整数、宽支持及非有限输出拒绝。复制不变性只适用于完整全局日所有相关行等倍复制，不承诺单行复制不变。输入记录/支持不变，外部 Decimal 当前/default context（含 traps/flags）不影响输出且不被修改。

冷子进程用 `-I -S -B` 实际导入并调用，导入围栏只允许标准库与本模块的三个包节点；审计钩子拒绝非代码业务文件、网络及外部操作。没有研究数据、MT5、labels/fit 导入或调用。

证据按每次运行保存完整命令、退出码、前后 tree、三个文件 raw SHA256 及源码快照。初始缺实现 RED 为4项失败；聚合阶段66项通过。已导入聚合核上的下界 RED 为4项失败。首次完整下界尝试91项通过、1项因临界测试常量选错失败，日志保留；独立有理区间查明并修正样例后92项通过，未改变核公式。最终版本另补三类混合和有限宽支持断言后，与直接相关的旧 `test_prob_tables.py` / `test_prob_decision.py` 一起定向验收。旧两文件基线为27项通过；最终数量及提交标识见同目录 `green-final.json`、`commit-verification.json`。
