## 3. 有限候选与共享基准处理

仅评估 **E0、V2-A、V2-B**：E0 是原形态负对照；A 是预先指定主候选，B 是机制对照，不开展参数搜索。
E0 保留原行权重、共享 per-action 基准、m=100、Wald 与原回退语义；新的日 ID 不能暗中修复 E0。
E0 的 KS/KI 适配器仅传入可见标签，维持其不处理截尾的缺陷；lookup 无可用数据时记录不可用且决策弃权，计主覆盖失败，不能用 a 伪装有界估计。
A/B 的共同中心按所选层 l 计算：日内结局比例 `Y_do`、结局收益贡献 `Z_do=mean(I_o*r)`，o∈{win,loss,time}。
令 `k_lo=sum_d Y_do`、`s_lo=sum_d Z_do`；动作池日等权 `q_o=mean_d Y_do`、`v_o=mean_d Z_do`。
`r_base,o=v_o/q_o`（q=0 时该项贡献为零且条件均值记未知）；`p_tilde,o=(k_lo+100*q_o)/(D_l+100)`。
`r_tilde,o=(s_lo+100*v_o)/(k_lo+100*q_o)`；分母为零时该项 EV 贡献为零，不能报告 r 已知为零。
因此中心 `mu_tilde=sum_o p_tilde,o*r_tilde,o=(sum_o s_lo+100*sum_o v_o)/(D_l+100)`；基准层自身用日均值。
该中心继续使用共享动作池，包含本格与其他局面；它只提供中心，不提供“100 个额外独立观测”的证据。
对截尾数据，中心仅用可见行并重算可见日统计；无可见样本时中心未知，候选下界直接取支持集下端。
安全区间始终从**目标格本身**构造；目标缺失不能靠污染池获得较窄区间。池中收益不确定度不能当作已知常量。
预设构造预算 `delta=0.01`，9 个白名单查询格等分 `delta_c=0.01/9`，不是从结果选择的超参数。
`lb_z` 仍传入 1.0；A/B 将“一倍不确定度”定义为下述保护量，**不同于旧 Wald 一倍标准误**。
此语义替换及 delta 与冻结产品契约的兼容性是独立审核必答问题；本稿不以配置未变冒充方法未变。

### 3.1 V2-A：日均值下界与中心偏移保护（主提案）

候选要求输入预先给定、可审计的收益支持集 `[a_o,b_o]`；令 `a=min a_o`、`b=max b_o`。
对完整日数据令 `W_dc=X_dc`；截尾行用 a 替代后作日均值，所得 W 是潜在完整日均值的逐样本下端。
`h_c=(b-a)*sqrt(log(1/delta_c)/(2*D_c))`；`D_c=0` 时直接 `L_A=a`。
有中心时 `L_A=max(a, mu_tilde-abs(mu_tilde-mean(W_c))-lb_z*h_c)`；无中心时 `L_A=a`。
定义支持下端裁剪后的目标格保护界 `B_A=max(a,mean(W_c)-h_c)`；`D_c=0` 时 `B_A=a`。
保护量不把基准偏移当抽样噪声：在冻结的 `lb_z=1` 下，任意共享池改变中心仍有 `L_A<=B_A`，不能借池突破本格保护界；该断言包含最外层 `max(a,...)` 的支持下端裁剪。
该式直接传播日收益的全部波动（含 p、r 及其协变），不使用插入式固定 r；全胜/全负时 h 也不消失。
支持集是适用假设，不是 winsorization：实际输入超界即停并保留原值，不静默裁剪，不据样本极值重估边界。

### 3.2 V2-B：概率/收益贡献联合可行域（对照提案）

每个结局定义 `T_do=mean(I_o*(r-a_o)/(b_o-a_o))`；`0<=T_do<=Y_do<=1`，支持宽度必须严格为正。
对本格 D 个日的六个统计量 `{Y_o,T_o}`，取 `h=sqrt(log(12/delta_c)/(2*D))`，同时构造两侧区间。
完整观测用 `[max(0,mean-h), min(1,mean+h)]`；截尾观测先将每个未知行的 Y/T 放入 [0,1]，再分别平均下/上端并加减 h。
可行域 Q 加入 `sum p_o=1`、`0<=t_o<=p_o`；理想值为 `L_rect^*=min_Q sum_o[a_o*p_o+(b_o-a_o)*t_o]`，数值返回值须认证 `L_rect<=L_rect^*`。
原始可行解目标是此最小值的上界，不能直接作为 `L_rect`；以下是运行前冻结的数值验收契约，不改变候选或统计预算。

- 固定结局顺序 win/loss/time，变量 `x=(p_win,p_loss,p_time,t_win,t_loss,t_time)`，目标系数 `c=(a_win,a_loss,a_time,b_win-a_win,b_loss-a_loss,b_time-a_time)`。以原尺度写原问题 `min c^T*x`，约束 `G*x>=g, E*x=1`；`E=(1,1,1,0,0,0)`。G 的1–6行为 `x_j>=ell_j`，7–12行为 `-x_j>=-u_j`，13–15行为 `p_o-t_o>=0`，均按上述次序；`g=(ell,-u,0,0,0)`，`0<=ell<=u<=1`。
- 常量按声明的精确值、输入有限 binary64 数按其精确有理值解释，日均值用有理算术计算。对 h 及区间端点使用固定256位、逐运算向外舍入的区间算术（含 log/sqrt），随后下端向下、上端向上转 binary64，再与 [0,1] 取交；该有理端点定义 `Q_out`，须有 `Q⊆Q_out`。任何无法包围、非有限或 `ell_j>u_j` 均 INVALID；不采用依结果变化的精度重试。求解在 binary64 进行，全部证书复核按冻结系数及返回 binary64 的精确有理值进行。
- 对偶固定为 `max g^T*y+z`，约束 `G^T*y+E^T*z=c, y>=0`，z 自由。求解原/对偶，要求成功且二者均为 OPTIMAL，并返回原始尺度的解 `x_hat,y_hat,z_hat` 及原始顶点基；可由同次求解提供。运行前记录并冻结求解器名称、版本、算法、预处理/缩放与容差设置，复核一律在原尺度进行。不可行、无界、超时、仅近似成功或缺证书均 INVALID。
- 固定绝对容差 `tau=1e-10`，不加相对或显示舍入容差。用精确有理算术检查 `max_i max(0,g_i-(G*x_hat)_i)`、`abs(E*x_hat-1)`、`max_i max(0,-y_hat_i)` 和 `||c-G^T*y_hat-E^T*z_hat||_inf` 均不超过 tau。由返回顶点基按行号取等式加5条独立紧约束（有多组取字典序最小），精确有理消元得到 `x_P`；缺基、奇异或 `G*x_P>=g, E*x_P=1` 任一不精确成立均 INVALID。原始上界 `U=c^T*x_P`，不得用于下界返回。
- 对偶修正先取 `y_i=max(0,y_hat_i), z=z_hat`，令 `r=c-G^T*y-E^T*z`，再要求 `||r||_inf<=tau`。对每个 j，将第 j 个下端乘子加 `max(r_j,0)`、第 `6+j` 个上端乘子加 `max(-r_j,0)`，其余不变，得到 `y_cert`。精确复核 `y_cert>=0` 及 `G^T*y_cert+E^T*z=c`；修正后的对偶目标为 `d=g^T*y+z+sum_j[ell_j*max(r_j,0)+u_j*min(r_j,0)]`。由弱对偶，`d<=min_{Q_out} c^T*x<=L_rect^*`，此残差修正给出可认证保守方向。
- 将精确 d 向下舍入成 binary64 的 `L_rect`，要求有限且精确复核 `0<=U-L_rect<=tau`，作为可行性/最优性的最终证书；未满足即 INVALID，中止且不回退成 PASS。保存冻结 LP 系数、原/对偶状态、基、原始解、修正乘子、残差、U、d、返回值和差距，足以独立重算；判定使用该未作显示舍入的认证返回值。

`D=0` 时 Q 为整个合法域、`L_rect=a`，直接使用解析下界，不求解 LP；有中心时 `L_B=mu_tilde-lb_z*max(0,mu_tilde-L_rect)`，无中心时取 a。
`r_o=a_o+(b_o-a_o)*t_o/p_o`；p=0 时条件 r 未识别但贡献为零，故传播的是联合贡献而非将 r 的标准误设零。
概率边界通过 [0,1] 与单纯形约束处理；k=0/n 仍有非零区间，禁止拼出负 time 概率。
B 的中心再受 L_rect 限制，其他局面不能缩窄本格区间；不因本批表现换为“最优”中心、预算或候选。

## 4. 与估计器独立的真值及收益生成器

生成器不导入估计器、ProbTable、EV 下界、lookup 或判定函数；truth 文件只供计量端，估计器只能接收标签/日 ID/支持契约。
父均值 `q(b)=(b,0.85*(1-b),0.15*(1-b))`；格间异质性 H 固定为 `{hom,200,40,4}`。
`hom` 直接取父均值；有限 H=κ 时，每次重复对各格独立抽 `Dirichlet(κ*q)`；零分量留零，仅在正分量子空间抽样。
只剩一个正分量时取确定角点；不沿用“分量<0.01 即取消异质性”的捷径。较小 κ 表示更强格间差异。
混合主档两局面父均值均为 q(b)；污染档固定 S1 为 q(0.1)，S2 为 q(b_other)，两动作相同设定，格内按 H 抽真值。
边界结构六档：AW/AL/AT 是全部格精确全胜/全负/全 time；PW/PL/PT 仅 S1 如此，S2 为 q(0.9)、H=hom。
每个父格有 N 个全局独立日；每日特征 f0/f1 各概率 1/2，按该格真值抽一次结局；同日 C 行共享该结局。
同日跨父格共用一个 Uniform 结局驱动（各自累积分布映射），用于压力测试同时相关；不同日驱动独立。
收益三个档 R={low,high,end}：原始角色均值 `(1.90,-1.05,0.10)`，支持分别 `[0,4],[-2,0],[-1,1]`。
low/high 分别为均值加等概率正负幅度 `(0.20,0.10,0.10)` / `(0.90,0.80,0.80)`；end 在各结局支持两端取值，以上端概率 `(mu_o-a_o)/(b_o-a_o)` 保持均值。
每个父格每日收益驱动由同日所有行共享，形成最强簇相关；C=3/10 是复制压力，不能增加 n_eff 或改变 A/B 输出。
每个条件再分 original/null 两角色；null 的三个结局均值全部为 `0.05 R`，支持统一 `[-2,4]`。
null 的 low/high 幅度固定为 0.10/0.80，end 仍按两端概率公式生成；标签仅表示结局类别，不假定 null 的 loss 收益必负。
null 真值恒等于成本，恰在无优势边界；这是明确的合成压力模型，不是对真实交易收益的描述或真实数据校准。
收益条件分布、概率真值和截尾概率均由生成器常量确定；真 EV 由解析期望计算，不从抽样样本或拟合表反推。

## 5. 缺失与 K 边界：明确不同真值

特征缺失 M∈{0,0.3}：整日特征以 M 概率改为 na，保留日 ID；与潜在收益/结局独立，不用逐行缺失制造额外信息。
K 四档：K0 无跨界；KT 以 0.5 概率把日结局改 time 并从 time 收益分布生成；KS 独立以 0.5 概率隐藏全部日标签；KI 按原结局 win/loss/time 概率 0.75/0.25/0.50 隐藏。
KT 的真值明确为**变换后** `p'=(0.5*p_win,0.5*p_loss,0.5*p_time+0.5)` 与对应收益均值；同时保存变换前真值，仅作诊断。
KS/KI 的目标仍为潜在完整日 EV；输入必须含所有计划触发日与缺失标记，不能丢弃跨界日后假称观测无选择。
KS/KI 由 §3 的支持界处理部分识别；不将 skipped 填为 time 或 r=0，不凭不可观测标签估计删除概率。
若未来接口不能提供总日框架/缺失标记或支持契约，则这些条件记“不支持/阻断”，不得从矩阵删除后宣称整体通过。
KT 是旧研究的简化变换对照；KS/KI 是独立截尾模型，均不声称精确复刻生产 labels。

## 7. 确定性种子与上下文

版本标识提案为 `d61-v2-design-01`，种子基 `20261103`；条件 JSON 按键排序、ASCII、无空格，数值档用枚举字符串避免浮点格式差异。
`seed(parts)=int.from_bytes(SHA256(UTF8(canonical_json([20261103,"d61-v2-design-01",*parts])))[:16],"big")`，RNG 固定 NumPy PCG64。
parts 按 `[block,role,condition,rep,draw,stream,parent,day,feat]` 定序；draw∈{world,sample-A,sample-B}，stream∈{truth,feature,outcome,return,missing,K,context}。
truth/context 使用 world；truth 的 parent 为 s:a、feat 为 f0/f1、day 为 -1；context 的 parent/feat 为 global、day 为 -1；样本流 feat 固定 global、day 为 0..N-1；跨父格共用的 outcome 流 parent 为 global，其余样本流为 s:a。
真值只含 truth 流，样本流不得回写真值；缺失/截尾使用独立流，KI 仅通过预写概率读取潜在结局。
rep 为 0..4999；上下文 f 在 f0/f1 等概率选，M>0 时再以 M 概率隐藏；每候选方向独立等概率 ±1。
计算每个白名单候选在其上下文特征的 L，按原 `decide_level` 语义处理字典序、方向冲突弃权、白名单与 2×成本门。
另外计算全部 9 个白名单查询格用于覆盖计量；分片、线程数、估计器顺序不进入种子，也不共享可变 RNG 状态。
相同协议与代码的重建须逐字节一致；修改任何代码/协议/输入常量生成新版本及 run_id，失败后不得换种子求通过。

## 8. 逐条件指标、误差与判定（待审核）

每条件/估计器记录指定 S1:A1 上下文覆盖、全部 9 格各自覆盖、以及主指标 `C_all=mean(所有9格 L_c<=theta_c)`。
选择使用同时覆盖作主门，避免异质性或候选选择被平均覆盖掩盖；指定格指标仅作与旧研究口径对照。
每重复以生成器真值认定 `null=all(theta_candidate<=0.05)`；误开放 `F=count(null且决策非空)/count(null)`，包含全部选择效应。
null 角色必有 5000 个空真重复；original 角色仅在 `null_reps>=100` 时判 F，否则明确 NA，不能记为零或 PASS。
报告全量分母、拒绝/回退率、支持下端占比、下界裕度分布、两次抽样决策一致率、逐格/逐结构最差条件；不以均值替代逐条件。
A/B 同时计量，预先上限 `J=2*2304*2=9216` 个二项主端点（C_all 与 F），包括暂为 NA 的 F，不能看结果减少 J。
用 `epsilon=0.05/(2*9216)` 的单尾 Clopper–Pearson 端点形成同时区间 [L,U]：下端 Beta(epsilon;k,n-k+1)，上端 Beta(1-epsilon;k+1,n-k)。
k=0 下端为0，k=n 上端为1；用原整数重复计数，禁止将日数、行数、伪计数或双抽样数当二项分母。
这是跨条件/候选/两端的 Bonferroni 95% 同时陈述，不假定端点独立；构造预算 delta 与 Monte Carlo epsilon 分开入档。
每条件覆盖 PASS 当 `L_C>=0.95`，RED 当点估计 `<0.80`，其他 WARN；另报 `U_C<0.80` 是否为确证 RED。
可判误开放 PASS 当 `U_F<=0.05`，RED 当点估计 `>0.10`，其他 WARN；另报 `L_F>0.10` 是否为确证 RED。
按冻结的 `epsilon=0.05/18432`，零误开时 `U_F=1-epsilon^(1/n)`，至少250个 null 重复才可能 `U_F<=0.05`；original 角色仅100–249个 null 重复时最多 WARN（点估计越过 RED 门仍为 RED），不能据此临时增加重复或放宽门槛。
点估计恰等边界按上述包含关系处理；没有增加舍入容差来开门。输出使用整数与未舍入端点，显示小数不参与判定。
方法研究 PASS 要求所有条件覆盖 PASS、所有可判 F PASS、null 角色无 NA、无不支持/缺失工件，并通过 §9 控制；任何 WARN/RED 均不放行。
E0 并列报原点估计两级门与本稿指标，不纳入新方法获准集合；不要求通过修改 E0 使它重现旧报告每一个数字。
A 是唯一预指定推进候选；A 不满足时即 NO_GO，B 单独通过不能被事后挑选顶替。B 若需推进须新版本、独立审核与新预注册。
即使 A 研究 PASS，也仅形成独立审核材料；本文与未来统计 PASS 均不自行解除旧 RED、D61 或 T92 阻断。

## 9. 合成控制、独立性检查与可复现工件

以下为**未来实现的测试规格**，本次仅做静态文档检查，不执行任何生成器、拟合、模拟或产品测试。
确定性正控制：N=1600、每格特征各800日、全胜且 r=1.90、无缺失/截尾、全部同方向；A/B 应有限且开放，防“永远弃权”伪通过。
确定性负控制：全部日 r=-1、成本0.05、全部同方向，任何方法开放均触发调查；不靠方向冲突掩盖误开放。
E0 已知缺陷哨兵：全动作胜、每行 r=2.10、生成器均值1.90，E0 的 p=1/SE=0 导致 L=2.10>真值；此为人工样本检查，不是频率结论。
重复行控制：整日复制1/3/10次，A/B 的日数、中心、区间、决策逐位相同；E0 按原行为保留差异，不能为让它通过而修正。
污染控制：固定目标格数据，只替换 S2 同动作数据；本格安全可行域不变。在冻结的 `lb_z=1` 下，A 须断言 `L_A<=B_A`（含支持下端裁剪及 `D_c=0`），B 有中心时须断言 `L_B<=L_rect`；B 无中心直接取 a，按支持下端保护。
边界/截尾控制：零样本、全胜/负/time、某结局未出现、全部 skipped、na、KS/KI；验证概率合法、收益未知不写零、潜在真值未偷换。
独立性绊线：估计器进程无 truth 输入；生成器不 import 估计器；断言无研究数据层/MT5 导入、无数据根访问、无网络访问。
未来在 rep 0/2499 对 E0 复刻与真实接口做金丝雀；不匹配立即停；A/B 的纯实现由独立审核者用小型手算例核查。
manifest 记录协议 SHA256、基点/实现提交、生成器/估计器/计量/决策适配器字节哈希、全部常量与输入契约哈希、依赖版本与环境。
run_id 为上述规范 manifest 核心字节的 SHA256 前16位；完整哈希保留，ID 碰撞拒绝；目录已存在拒绝覆盖。
