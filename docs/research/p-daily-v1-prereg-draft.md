# P-Daily v1 预注册草案（冻结统计口径、效应来源与成本主口径）

- 状态：**草案（待用户批准后冻结）**。对应 P 线重设计步骤 1 / 审核条件 D1（提交唯一版本的预注册）。
- 上游文件：设计摘要（`.superpowers/p-line-redesign-codex-v2.md` 会话）、独立审核（`.superpowers/p-line-redesign-review.md`，CONDITIONAL 裁定九项风险 + 五条件）、数据清单（`docs/research/p-daily-v1-qualification.json`，步骤 2）、检验力报告（`docs/research/p-daily-v1-power-analysis.md`，步骤 3）。
- 本文件只冻结口径与规则；**不构成开卡**。开卡前提见 §10。

## 1. 研究对象与主假设

**P-Daily v1** = 三品种（XAUUSD、EURUSD、USDJPY）共享的日频概率模型：每合格交易日在固定时点做一次概率评估，输出方向（多/空/空仓）、仓位（0 或 0.01 手，低于最小手数即空仓）与止损距离。

- **主假设（科学层，H1）**：模型对 P(日收益>0 | 特征) 的样本外预测具有校准技能——样本外 **Brier 技能分 > 0**：
  - Brier 分：B = (1/n)Σ(pᵢ − yᵢ)²，yᵢ ∈ {0,1} 为次日方向实现；
  - 基准 B₀：无条件日频上涨概率 p̄（**只用训练段**估计）的 Brier 分；
  - 技能分 SS = 1 − B/B₀，在**样本外段**计算；H1: SS > 0。
  - 判定方式（诊断层）：按月块自助的单侧 p 值（2000 次，预写种子），p ≤ 0.05 报告"校准技能成立"；**该校验不作为放行门**，只作为科学假设的证据记录。
- **放行判定（决策层，唯一主检验）**：同一模型生成的三品种等权组合样本外净收益序列，通过冻结关卡 v3 方案甲（§2）+ 三项稳健性否决。概率校准好但交易不赚钱（或反之）都只在报告中记录，不改变判定。
- 假设上述两层**不同时**成功时：以决策层为准放行与否，科学层结果进诊断报告（防止用校准技能替代经济判据——审核风险 5）。

## 2. 主检验入口（与现行 gates.toml 一致，不放宽）

- 主检验：**DSR(N, V₀) ≥ 0.95**（`config/gates.toml` v3 `primary_test="dsr_v0"`，冻结 sha 校验）；V₀ = 1/(n−1)，n = 样本外观测数；SR₀ = term(N)/√(n−1)。
- **试验 N（rounds_lineage 口径）**：N = ledger.primary_test_n(continues_family) = project_n_dedup_rounds + lineage_n_dedup。P-Daily v1 为**新谱系**（lineage = 0）。台账实测（2026-11-16，只读）：project_n_dedup_rounds = 2 → 今日 N_eff = max(2, n_min=2) = 2；正式开卡时本候选自身轮次试验计入后 N ≥ 3。**检验力规划与预筛统一按 N = 3**（term(3) = 0.8528，比 N=2 更严，方向保守；判定时以台账当日读数为准）。
- 附注：DSR(N, V₀) 与"单侧 Bonferroni α=0.05/3"是**不同规则**（后者临界量 2.128 < 前者 2.4977）。本预注册用 DSR 估检验力、用 DSR 判定，不混用（审核纠正项）。
- 稳健性否决（全部否决，沿用 [v3]）：成本 ×1.5 每笔净利均值仍 >0；信号延迟一根 bar 净利仍 >0；纯多头时夏普须超同期买入持有（非纯多头不适用）。
- 事件/概率模式的 G1/G2 诊断层照现行配置只报告不否决。

## 3. 收益单位与决策/持有规则（三个时钟分离）

- **模型输入频率**：D1（已完成日线）特征；不使用 H1 特征（若未来引入，该日须另行满足真日内资格——本版本明确不用）。
- **决策频率**：每合格交易日一次。决策时点 = 服务器 D1 bar 收盘后、下一 bar 开始前（信息截止 = 当日 D1 收盘的全部数据）。
- **成交/评价频率**：bar 级。入场 = T+1 D1 bar 开盘价；出场 = T+1 D1 bar 收盘价（单日持有，每品种每日至多 1 笔；**无止损后重入**——与"每日最多一次入场"一致，审核 §B.1 风险）。周五产生的意图在下一合格交易日（周一）开盘执行。
- **止损语义**：T+1 日内虚拟止损按 D1 low/high 触发判定（bar 级近似）；触发则以止损价出场（同 bar 内先止损后到目标价时按止损计，保守）。标签用实际出场价训练，不假设亏损恰等于止损距离。
- **收益单位**：市场收益 = 相邻合格交易日 D1 收盘的对数收益（收盘到收盘）；**持仓实际净收益** = 开盘到收盘、扣除 §5 全部成本后的对数收益（主检验消费的是后者）。两者差异（隔夜跳空）入诊断报告。
- 三个品种同日才产生组合观测（见 §7 切分）；任一品种当日不合格 → 该日组合无观测。

## 4. 交易日定义（D1 资格规则，替代旧 H1 规则）

- 交易日 = bar 时间戳的 **UTC 日历日**；仅周一–周五可合格（周末一律排除）。
- 合格日 = **任一已批准来源该日 H1 根数 ≥ 20**（真实日内会话存在，杜绝伪 H1）**且任一来源该日存在合法 D1 OHLC**（四价 > 0；low ≤ min(open,close)；high ≥ max(open,close)）。
- histdata 仅使用 manifest.yearly_verification 标 `used=true` 的年份（EURUSD 2003–2005 inconsistent、2006 undetermined 不用）。
- 全局研究 cutoff（锁箱）= **2025-10-24T00:00Z**（只能更早不能更晚）。库内晚于 cutoff 的 USDJPY 行一律截断。
- 已批准来源（冻结）：XAUUSD = histdata(2009-05→2021-12) ∪ MT5(2014-01→2025-10)；EURUSD = histdata(2007-01→2025-10) ∪ MT5(2021-05→2025-10)；USDJPY = MT5 only（1971→cutoff，早年伪 H1 由 ≥20 H1 规则自动排除，实测首个合格日 1999-01-05）。
- 逐品种计数、排除原因与共同覆盖：见 `p-daily-v1-qualification.json`（实测：合格日 3,969/4,846/6,923；共同覆盖 3,931 天，2009-05-01→2025-10-23）。

## 5. 成本主口径（charged，现行 D84）

- **主口径 = charged**（D84：Demo 免隔夜费记为事实，研究成本口径保持 charged）。free（返还口径）只作披露列，不进任何判定。
- 每笔来回成本（相对价）= spread_p90(决策小时 NY 分桶，`costs/spread_model.json` v2) + 2×滑点(0.1×spread) + 佣金（calibrated = 0）。
- 隔夜费（charged）：**保守读法为主口径**——每持有日计 1 晚 rollover（周三 ×3，即按 7 晚/5 交易日 = ×1.4），按方向×品种×费率计（specs 快照：XAUUSD 多 −490 点/手/晚、空 0；EURUSD 多 −5.9 USD/手/晚、空 0）。注：引擎语义为 D1 单日持有（开盘入/收盘出），是否跨 rollover 计费取决于经纪商实现——宽松读法（0 晚）作敏感性披露（检验力结论对两种读法稳健，见 power-analysis §5）；开卡前在 Demo 用零风险交易实测计费行为并回填。
- **已知缺口（开卡前必须补齐）**：USDJPY 无 spread 模型、无 specs、无 swap 标定——charged 口径在三品种上当前无法闭合。处理选项（按序）：(a) 补 USDJPY 成本标定；(b) 降为双品种（XAUUSD+EURUSD）并按本预注册重算共同覆盖与检验力。**缺口未闭合前不得开卡。**

## 6. 发表后效应折算链（效应来源冻结）

- 文献锚点（发表时、净成本、多品种组合日-月频动量/趋势类）：SR 0.8–1.0（Moskowitz–Ooi–Pedersen 2012；Hurst–Ooi–Pedersen 2017；AQR 2018 引净 SR 0.76）。规划基准带：常见日频策略组合净 SR 0.1–1.0。
- 三品种/单资产类折减：0.2–0.5（分散化损失，定性折减并披露）。
- 发表后衰减：保留比例 0.42（McLean–Pontiff 2016：发表后 −58%）。
- **发表后预期毛效应带：每品种 SR 0.08–0.21**；乐观上限（不衰减 + 文献顶部）：0.8–1.0。
- charged 成本墙（实测）：折合每品种年化 SR 0.16–0.30（XAUUSD 0.225 / EURUSD 0.300 / USDJPY ≥0.162）。**预期带整体落在成本墙之下或附近。**
- 检验力结论（详见步骤 3 报告）：实际 OOS 3,227 天达到 50% 检验力需组合年化净 SR ≥ 0.70（每品种毛 SR ≥ ~0.8 且不衰减）。**按可辩护效应带，P-Daily v1 当前检验力 ≤0.5% → waiting_data。**

## 7. 切分、预热与重训

- 训练/样本外：**24/6 月滚动 walk-forward**（与 gates.toml [g3] hourly 档同构）：共同覆盖（3,931 天）扣预热 200 交易日 → 可用 3,731 天；前 24 个日历月初始训练，其后每 6 个月用**过去 24 个月**重训；第 24 个月起每个合格日恰属一个样本外窗（实测 OOS = 3,227 天，2013-01-02→2025-10-23）。
- 预热 = 200 个共同合格交易日（日频特征最长回看规划值）；预热段不产生 OOS 观测。
- 重训纪律（防泄漏，审核风险 8）：三品种**按同一时间轴**切分；标签在训练期末已成熟（T+1 收盘已知）；标准化参数、特征选择、超参只用训练段信息；禁止"品种×日期"随机拆分。
- 单切分 70/30 仅作对照（OOS 1,120 天），不作判定（所需组合 SR 1.19 超出文献锚点）。

## 8. 样本量预注册（铁律 18）

- 以 N=3、OOS n=3,227、DSR 方案甲：50% 检验力所需组合日频效应 s₅₀ = 0.0440（年化净 SR 0.70）。
- 预注册最低有意义效应：组合年化净 SR = 0.5（低于此即使"未显著"也不值得继续；用于等效性披露，见 §9）。
- 当前效应带（§6）下检验力 <50% → **本候选不开卡，入"待数据"队列**；重开条件 = §10。

## 9. 三类结论的含义（预写）

1. **通过（pass）**：OOS 结束时 DSR(N=3, V₀) ≥ 0.95 **且** 三项否决全部通过 → 进入影子运行阶段（后续条件 D4/D5）。
2. **待数据（waiting_data）**：开卡前检验力 <50%（当前状态），或运行中数据未成熟。不做任何交易动作；台账记录证据缺口。
3. **无效（falsified）**：OOS 结束未通过主检验 → 谱系关闭，按预注册记录；"未显著"**不得**表述为"证明无效"。若需经济学无效结论，按预注册最低有意义效应（SR 0.5）报告单侧上置信界：UCB₉₅ < 0.5 才可写"经济上无意义"。
- 中途不得改口径、换品种、调阈值后重跑（同一谱系重测 = 新试验，计入台账 N）。
