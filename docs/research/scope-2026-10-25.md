# 可交易性审计结论（2026-10-25，修复轮 T8 收尾）

数据与方法：四品种真实 tick（XAUUSD 7,780 万条 / USTEC 2,010 万 / BTCUSD 170 万 /
EURUSD 44 万），**相对点差口径**（(ask−bid)/mid 按小时 p90，随价格水平缩放，R1/T3）；
波幅为 (high−low)/close 的小时均值（比率不随价格水平变化）；佣金按实测 0
（Exness 标准账户点差内含，见 data/reports/costs/calibration.md）；滑点 0.1×p90。
判定阈值 0.12（来回成本 ÷ 该周期平均波幅 ≤ 12%，附录 B 初始准入线）。
热力图：`data/reports/costs/heatmap.csv`（16 行 × 24 小时）。

## 排除

- **M1 信号周期（全部品种）**：蓝图既定不做 M1 剥头皮；成本侧 XAUUSD（最好
  0.121，贴线）与 EURUSD（0.254+）也确实不可行；BTCUSD/USTEC 的 M1 虽过线
  （0.054 / 0.038），仍按蓝图原则排除——留作 B 层执行/止损模拟的数据周期。
- **EURUSD M5**：仅 2/24 小时过线，实际不可交易。
- **XAUUSD M1**：0/24。

## 禁止交易时段（UTC）

- **21:00–21:59（换日/结算窗，全部非加密品种）**：点差 p99 放大数倍至两个数量级
  （EURUSD M5 达 4.6×波幅、M1 达 11.8×；XAUUSD 各周期该小时均最差）。
  风控（P7/T14）应硬编码禁止此时段开仓。
- **22:00–22:59 EURUSD**（残余换日影响，M15 2.5×）——EURUSD 建议把禁止窗
  延到 23:00，或按小时成本表动态判定。
- BTCUSD 无换日窗（24/7），无禁止时段；周日开盘后首小时内点差偶发尖峰
  （建议 P7 心跳监控点差 >3×p90 时暂缓开仓，非硬禁止）。

## 与上一版（绝对口径）结论的差异

绝对口径把点差固定在近期价位套全历史，XAUUSD 早年（金价 1/3）成本被高估约 3 倍。
相对口径下 XAUUSD M5 从"全排除"变为 18/24 纳入，BTCUSD 全周期翻绿——
这是 R1 修复的实际影响，也说明此前"XAUUSD M5 不可交易"的结论是口径伪影。
