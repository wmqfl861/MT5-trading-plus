## 1. 设计摘要（预注册，先于结果冻结）

- **method_id = `cluster-permutation-v1`**（`prob_mode.cluster_permutation_test`，独立函数，`delta_p_test` 缺省路径逐位不变）；统计量不变：触发组日赢率均值 − 随机组日赢率均值（日聚合 Δp，D52）；
- **交换单位=簇**：real+null 合并触发日按时间邻接聚簇，`CLUSTER_GAP_DAYS=10` **日历日**（跨月不拆；括注修正：≈7 个交易日，不字面覆盖审核模拟的 10/20 交易日簇，跨簇残余相关由 cluster 相位实测）；每次置换把全部簇随机重分两组、统计量按日重算（簇内各日随簇走，自然带簇权重）；
- **组簇数 = 混合簇多数归属计数**（real 日数 > null 计 real、< 计 null、**平局计 real**——确定性规则），重分时两组目标簇数取该计数；重分后两组日数不守恒（最大簇可占相当日数份额），按预注册披露进审计输出（`perm_mean_days_real|null`）；
- **最少交换单位**：任一组目标簇数 < `MIN_CLUSTERS_PER_GROUP=5（实现另以总簇数 ≥10 为门槛，替代计划字面的 C(n,k) 最小可达 p>0.001——偏离声明：实测 4,320 个可检验行 C(n,k) 全部 ≥1000，0 行触达差异，判定不受影响）` 或总簇数 < 10 → **不可检验**（返回明确状态，不打碎簇凑样本）；审计输出：簇数/簇大小分布/最小可达 p/两组日数观测与置换均值；
- **匹配与资格不变**：消费批 2 的 EligibilityContext，`randomize_triggers` 的合格 bar 池匹配（NY 小时/星期/ATR 档）不变——本方法只改 p 值的置换单位，不改 null 构造；
- **seed 基一次写定**：S_NEG=20261101、S_HOLM=20261102、S_POS=20261103、S_CLU=20261104、S_BRI=20261105；两段支持：第二段跑种子下标 ∈ [500,1000)，经段偏移派生、与首段值域不相交，分片落 `<phase>-st2-sIofN.json`；
- **manifest v2**：job 完备集 + 唯一性 + 分片指纹校验；cluster 输入在 pool 阶段冻结（P2-07：不再由 cluster 相位重读研究库）；
- **条件可交换依据**（审核 §4.3 步骤 3）：成簇对照下 real 与 null 是同一冻结触发集的独立刚性平移，簇级标签近似可交换；正式 P1（real 成簇 vs 桶匹配随机 null）下簇级可交换是**结构性假设**——适用边界在 §5 显式声明。

## 5. 不可检验与适用边界（独立小节，必须随方法披露）

即使未来某方法通过全部验收，**适用范围声明必须携带以下边界**（当前池密度下）：

- **n ≥ 2000 结构性不可用（分辨率死）**：pos 全部 6 个 n∈{2000,4000} 格功率 0（0/99、0/77 × 3 档）。机制（本报告从分片 audit 重算核实）：高密度抽样使合并触发日坍缩进 ~31 个簇（中位；n4000 可检行最大簇中位 **1,903 天**、合并总日数实测 [3,429, 3,506]（中位 3,474）——巨簇约占全部日数 **~55%**），k_real 中位 22（n2000）/25（n4000）；`min_achievable_p` 仍为 Monte Carlo 下限 1e-4（0/100 行超过 0.05）——**不可拒绝的原因不是组合分辨率下限，而是巨簇归属主导的置换零分布展宽**（审计记录的两组日数置换均值剧烈波动），植入 Δp 淹没其中；经验 p 值下限：n2000 全 12 格最小 p = 0.053（dp0.05）、n4000 = 0.22——检验在此结构下无法拒绝。另 n4000 有 23/100 直接不可检验（k_null ≤ 4 < 5）；neg n2000 亦 8/500 不可检验（同因）；
- **cluster 对照不可检验率 32–49%**：四格（w3/w7 × 首段/二段）= 31.6% / 38.2% / 41.0% / 49.2%；原因细分（重算）：绝大多数是"real/null 至少一组无可用触发日"（w3 140/158 与 178/191、w7 192/205 与 232/246——平移越界丢弃后一组触发日耗尽），其余为最少交换单位不足；这使可检种子数（342/309/295/254）低于名义 500，判定功效受限；
- **簇级可交换是结构性假设**：成簇对照只验证对称情形（同一冻结触发集的独立刚性平移）；正式 P1 的 real 成簇 vs 桶匹配随机 null 下 CI 是条件模拟误差，不覆盖所有市场（计划 §一 预写声明）；
- 池只含 XAUUSD（D53），EURUSD 加入后需扩充重跑。
