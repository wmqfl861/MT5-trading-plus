# 历史候选分诊表（T154，2026-11-13）

口径：**D76**（D68 修订，第十八轮 D84 代决生效，取代 D68）。Demo 路线要求同时满足：

1. 历史检验按预注册通过；
2. 发表后效应量下历史检验力 ≥ 50%；
3. 最近十年或发表后分段扣成本为正；
4. 有前向监测计划（逐笔回测与实盘对账、成本漂移、停止条件）。

前向检验力年数只作披露、不作门槛。研究成本口径保持 charged（U5/D84）；swap_free/charged 双口径数字并列时如实标注。判定三档：**进 Demo 路线 / 只作历史复现（含"待重检"） / 弃**。

范围：`research/candidates/` 全部登记（C001–C005、C101–C106、C900–C909）与蓝图提及的其他对象（§6.1 标定样品、§6.6 趋势类条件）。本表纯离线：只引用既有登记、预筛留痕、轮次报告与文献结论，未下载任何数据、未连终端、未计算任何策略收益或夏普（表中全部夏普/检验力数字均为登记时文献折算值与台账 precheck 留痕的转录）。
