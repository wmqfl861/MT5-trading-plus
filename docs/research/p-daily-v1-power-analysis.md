## 0. 方法

- 主检验 = 冻结方案甲 dsr_v0：DSR(N, V₀) ≥ 0.95，V₀ = 1/(n−1)，SR₀ = term(N)/√(n−1)，term(3) = (1−γ)Φ⁻¹(1−1/3) + γΦ⁻¹(1−1/(3e)) = 0.8528。**不是**"单侧 Bonferroni α=0.05/3"（其临界量 2.128 < DSR 的 2.4977；用宽规则估检验力、用严规则判定是审核明令禁止的混同）。
- 检验对象 = 三品种等权组合的样本外（OOS）日频净收益序列。
- 单品种净效应 d（日频标准化均值，charged 口径）× 等相关 ρ → 组合日频夏普 s_p = d·√(3/(1+2ρ))；年化 SR = s_p·√252。
- 解析近似（正态收益，DSR 闭式）出全网格；关键格用冻结入口 `run_primary_test(n_trials=3)` Monte Carlo 复核（seed=20261116，每格 2000 次独立模拟，报告 Wilson 95% 区间）。
- 实际样本量（步骤 2 实测，非日历上限）：**OOS（24/6 滚动）= 3,227 天**（2013-01-02 → 2025-10-23，12.8 年）；单切分 70/30 备选 = 1,120 天；预热后全部可用 = 3,731 天（理论上限）。

## 5. 发表后效应折算链（从文献到净效应）

折算链（每一步给出依据，不做无依据假设）：

1. **文献锚点（发表时、净成本后、多品种组合）**：时间序列动量/趋势类日-月频策略，58 品种组合净 SR ≈ 0.8–1.0（Moskowitz–Ooi–Pedersen 2012；Hurst–Ooi–Pedersen 2017 百年样本；AQR 2018 引用净 SR 0.76）。常见日频策略组合净 SR 范围按 0.1–1.0 取值（本步骤任务给定基准带）。
2. **三品种/单资产类折减**：上述数字依赖 50+ 品种分散。仅 3 品种（其中两个共享美元风险因子）的现实子带取 **0.2–0.5**（分散化损失按 √(58/3) 量级折减非系统成分，定性折减、不装精确）。
3. **发表后衰减**：McLean–Pontiff (2016, JF)：97 个已发表异象发表后收益平均 **−58%**（样本外但未发表 −26%）→ 保留比例 0.42（项目默认值，与文献一致）。
4. **发表后预期毛效应带**：0.2–0.5 × 0.42 ≈ **SR 0.08–0.21**；乐观上限（不衰减，且效应处于文献顶部 0.8–1.0）≈ **SR 0.8–1.0**。
5. **成本换算（charged 主口径，每交易日一来回 + 一晚隔夜）**，读自 `data_research/costs/spread_model.json`（p90）、`calibrated.json`（佣金 0）与 `specs/latest.json`（swap）：

| XAUUSD | 4.9e-5 | 5.9e-5 | 1.19e-4（−490 点/手/晚 ÷ 4,121.8） | 1.001% | **0.0142** | **0.225** |

按实际价格相关矩阵（含负相关）作代理时更乐观（毛 0.5 → 组合 SR 0.50 → power 0.24；毛 0.8 → 1.06 → 0.90），但价格相关 ≠ 策略净收益相关，该行仅作敏感性上限披露，不作结论依据。

## 8. 联合检验力与未计入损失（披露）

本报告的数字是**统计入口**的检验力上限。正式判定还须通过三项稳健性否决（成本 ×1.5、延迟一根、买入持有超额）与 G5；模型拟合退化（样本外低于理论效应）、空仓日稀释（有效 OOS 观测 < 3,227）、收益厚尾/自相关、USDJPY 成本缺口修补后成本只升不降——全部单向压低检出率。方向上：**真实可达检验力 ≤ 本报告数值**。

## 9. 最终结论

**P 线（P-Daily v1）：waiting_data（待数据）。**

依据：

1. **数据侧（已闭合）**：合格样本外窗口实测 3,227 天（12.8 年，三品种共同覆盖、预热与 24/6 切分后）。达到 50% 检验力需要组合年化净 SR ≥ 0.70（charged 口径）。
2. **效应侧（不可辩护）**：发表后效应折算链给出的可辩护范围是每品种毛 SR 0.08–0.21（发表时 0.2–0.5 × 0.42 保留）→ charged 净组合 SR ≈ −0.17…−0.02（**低于成本墙，净效应为负或零**）→ 检验力 ≤0.5%，n₅₀ 无穷。即使不衰减地保留发表时 0.5/品种（净组合 SR 0.33），检验力也只有 9.5%（n₅₀ = 14,246 天 = 56.5 年）。数据固定、效应不足：这不是收集更多同类数据能解决的缺口（每年新增 ~252 天，对 n₅₀ 万天量级无意义）。
3. **唯一可达窗口**：真实效应处于文献顶部（发表时净 SR ≥0.8/品种）且**不发生发表后衰减**且 ρ≤0.5 时，检验力 ≈50–92%。此窗口无发表后证据支持，不能作为规划基础。
4. **附带硬缺口**：USDJPY 无点差模型、无 specs、无 swap 标定——charged 主口径（D84）在三品种版本上今天无法闭合；正式开卡前必须补齐或降为双品种重算（共同覆盖会进一步缩短）。

按预写规则（铁律 18：检验力 < 50% 不开卡）P-Daily v1 进入"待数据"队列；同时记录：**除非出现"发表后净 SR ≥0.7 的三品种日频机制"的新证据（文献或前向），否则等待期实质无限**——若一年内无此类证据，下一裁决点应把 P 线从 waiting_data 改判不可行（作为日频共享概率机制的当前数据规模上），并把 P 线保留为方法研究（设计文档与预注册草案存档，不投入实现）。
