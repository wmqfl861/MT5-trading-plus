### 2.3 方向规则

| 项 | 写死的值 |
| --- | --- |
| 信号品种 | USTEC 日线收盘，只出信号不下单。研究库覆盖 39.81 年（ext §9.5） |
| 信号窗口 | 上月倒数第二个交易日收盘 → 本月倒数第二个交易日收盘。两个收盘都必须严格早于入场 |
| 方向 | 涨跌 > 0 取"USD 贬值方向"，< 0 取"USD 升值方向"，= 0 该月所有币对都不交易 |
| 折算到币对 | EURUSD、GBPUSD、AUDUSD：USD 贬值就是做多。USDJPY、USDCHF 是 USD 报价对：USD 贬值是**做空** |
| 阈值与权重 | 阈值 0，任何非零涨跌都触发；0.02 变体不登记、不运行。各币对等权 |
| 随机化检验 | 随机事件入口按同一规则重新算方向，不沿用实际事件的方向 |
| 禁止 | 不按币对另选信号，不调阈值，不在看到结果后改方向映射 |

**没有采用的三种写法**（写明理由，免得日后重新讨论）：各币对用本国股市当月涨跌，要英、日、瑞、澳四国股指日线，研究库里没有，FRED 的批准范围只有纳指 100（D60 方案 §2.2）；无信号的固定方向，R1 的 run 450 实际跑的就是"固定做多"，D58 已认定它不是 C002 登记的机制；按每日定盘窗、用 Krohn 等（2024）的"定盘前升值、定盘后反转"定方向，T155 §3 已写明要收窄到月末，该文的逐币对方向在仓库里没有转录。

**风险披露**：把"USTEC → EURUSD"的规则套到其余四个币对，等于把"美股上涨 → 该国货币贬值"里的"该国货币"读成"USD 对所有货币"。仓库登记只转录了 EURUSD 一个交易品种（C002 的 `published_effect`）。原文是否覆盖 USD 对 GBP、JPY、CHF、AUD，**待文献核查确认**。

### 2.4 主检验与合并口径

| 项 | 写法 | 依据 |
| --- | --- | --- |
| 主检验与随机化 | 随机化参照检验，单侧，p ≤ α/N（α = 0.05，复用冻结的 `[v3]`）。各币对共用同一组随机日期（成组随机化），保留星期分布和月内位置，不与原事件窗重叠；随机事件入口按同一方向规则重新算方向。随机化次数不少于 max(1999, ⌈20N/α⌉)；N ≤ 4 时是 1999 次（算术：20 × 4 / 0.05 = 1600） | 蓝图 §6.4（D35） |
| 检验单位 | 事件月。同一事件日各币对的净收益等权平均，成一个观测。名义上 5 × 12 = 60 个"币对-月"每年（T155 §3）；同日折叠后的独立观测是 12 个每年 | 蓝图 §6.4；`validation/events.py` 的 `aggregate_daily` |
| 主检验段 | 只用盲段。EURUSD 腿取 [2007-01-01, 2021-05-17) 的 HistData 段；其余币对取各自过闸的全程。盲段指本项目没有在真实事件时间上看过其收益的段。非盲段只作诊断，并标"非盲" | T114；蓝图 D58 |
| 诊断（只报告） | 逐币对净均值与 p 值、年块自助、事件窗前后平移一根、分段均值（2015-02-15 前后、最近十年）、已知缺口注记 | R1、R3 先例 |
| 缺窗 | 某币对某事件月缺入场或出场 bar，该币对该月不出事件，并登记"缺窗"。不补 bar、不换日、不插值。缺窗清单在资格核验阶段生成并冻结：它是覆盖的函数，不看收益 | 草案拟定，§10.1 第 6 项 |

## 6. 检验力
### 6.1 公式与取值（T155 §1 的口径，Lo 2002 近似）
- 组合夏普：`SR_p = SR_a · √(M / (1 + (M−1)ρ))`。标准误：`SE = √((1 + SR²/2) / T)`。检验力 = `Φ(SR_p / SE − z)`。
- z：N = 1 取 1.645，N = 2 取 1.960，N = 3 取 2.128（F1 报告 §2）；N = 4 取 2.241（算术：Φ⁻¹(1 − 0.05/4)）。
- 反解（算术）：50% 检验力要求的组合夏普 `SR_p* = z / √(T − z²/2)`；所需年数 `T50 = z²(1 + SR_p²/2) / SR_p²`。

### 6.4 达到 50% 需要什么条件（M = 5；算术）

| 窗口 | 需要的组合夏普（N=1 / N=3） | 需要的币对平均夏普（N=1；ρ=0.4 / 0.6） | 四个新币对各至少多少（EURUSD 腿 0.419；ρ=0.4 / 0.6） | ρ 上限（N=1；乙 / 丙） |
| --- | --- | --- | --- | --- |
| 18.72 年 | 0.395 / 0.525 | 0.285 / 0.326 | 0.251 / 0.302（EURUSD 的 60% / 72%） | 0.47 / 0.26 |
| 13.14 年 | 0.479 / 0.645 | 0.346 / 0.395 | 0.327 / 0.389（78% / 93%） | 0.24 / 0.09 |
| 10 年 | 0.559 / 0.765 | 0.403 / 0.461 | 0.399 / 0.472（95% / 113%） | 0.11 / 0.00 |

1. **窗口**：50% 只在长窗口可达。按乙，所需年数 T50 是 17.0 年（ρ = 0.4）到 21.8 年（ρ = 0.6）；按丙是 23.6–30.5 年。只用盲段（13.14 年）时，乙是 36–42%，丙是 29–34%。
2. **效应量**：四个新币对的隐含夏普要不低于 0.25–0.30（全样本，ρ = 0.6 到 0.4），即 EURUSD 的 60–72%；"折半"（0.21）不够。只用盲段时要 0.33–0.39，即 EURUSD 的 78–93%。
3. **相关**：ρ 要不高于 0.47（乙，全样本）。ρ = 0.6 时乙的上限是 `SR_a / √ρ` = 0.387，低于需要的 0.395，币对再多也到不了。丙要求 ρ ≤ 0.26。
4. **校正**：改按 α/N（N=3）判，三个门槛同时抬高：组合夏普 0.525（全样本），币对平均 0.38–0.43，ρ ≤ 0.16。
5. 以上依赖的五样东西——各币对的 σ、点差、过闸后的覆盖、ρ、主检验窗——都要等数据资格核验。**在那之前，"F3 能不能到 50%"没有答案。** 本草案不判 F3 的预筛状态。
