## 1. 目标与范围

目标：agent 负责提出和检验假设、写代码、做监控；实盘只由通过验证关卡的确定性代码执行，
并受独立风控约束。

- 标的：XAUUSD、BTCUSD、EURUSD、USTEC（纳指 100，Exness 品名）
- 信号周期：M5、M15、H1（H4 可选）；M1 与 tick 用于执行、止损管理和 B 层回测
- 账户：Exness 模拟盘 → 小资金实盘
- 暂不做：LLM 参与逐笔决策；M1 及以下剥头皮（除非成本审计证明可行）；机器学习黑箱模型

## 3. 架构（实现版）

```
MT5 终端 ⇄ mt5gw（唯一入口：行情/账户/交易，保险丝）
              │
              ├─► mt5data（Parquet 仓库：K 线、tick、质检、重采样、时段、锁箱、序列清单）
              │        │
              │        ├─► mt5quant（研究：成本、策略接口、A/B 引擎、报告；
              │        │            经 lockbox.research_bars 读数，读不到锁箱段）
              │        │        └─► validation 关卡 G0–G5 ─► 过关的策略代码（同一份）
              │        │                                           │
              │        └─► mt5mcp（只读、有界；给远程 agent，经隧道访问）  │
              │                                                    ▼
              └◄──────── mt5live（待建：信号运行器 → 风控进程 → 执行适配器 → 对账/监控）
```

| 包 | 职责 | 状态 |
| --- | --- | --- |

| `mt5data` | 数据仓库与数据质量；锁箱加载器 `research_bars` | 稳定（R2/R3 待改） |
| `mt5mcp` | 远程只读数据服务 | 功能稳定，部署不安全 |
| `mt5quant.costs` | 点差、滑点、佣金、隔夜费、可交易性审计 | R1/R4 待改 |
| `mt5quant.strategies` | 策略接口（参数 ≤4、网格 ≤100）与策略库 | 稳定 |
| `mt5quant.backtest` | A 层引擎、报告、manifest、截断测试 | A-1.1；B 层待建 |
| `mt5quant.research`（待建） | 假设卡、试验台账、`bt` 命令行 | P4 |

## 4. 铁律（v2）

1. **时间**：库内时间是"贴 UTC 标签的 naive datetime"，实为经纪商服务器时间。Exness 服务器
   为 GMT+0，所以目前等于 UTC。R5 已落地：配置声明 `server_utc_offset_hours`（默认 0.0），
   刷新与回测启动时用实测时钟校验（`mt5data.clock`），不符即拒绝运行；行情静默时跳过并记录。
   交易时段一律用 zoneinfo 按交易所本地时间换算。
2. **金额**：价格单位与账户货币严格区分。`run_backtest` 的 `contract_size` 必填；
   成本模型每个方法都在 docstring 写明单位（价格单位 / 每手金额）。
3. **只用已收盘 bar**：信号在 bar i 收盘产生，bar i+1 开盘成交。
4. **Bid 基准**：K 线按 Bid；多头 Ask 入场、Bid 出场，空头相反；SL/TP 触发口径与 MT5 一致
   （多头按 Bid、空头按 Ask）；跳空穿过止损按开盘价成交。
5. **同一份策略代码**用于回测与实盘；P4 起每个策略必须通过**窗口不变性测试**
   （实盘只用最近 `lookback_bars` 根计算信号，结果必须与全史计算一致）。
6. **锁箱**：全部品种、全部周期共用一个固定 cutoff，一经写入不得前移；锁箱只能为
   一张假设卡使用一次，使用记录进试验台账。
7. **可复现**：每次运行写独占目录 + manifest（git 提交、数据哈希、参数、成本版本、引擎版本、
   数据区间、合约大小）；所有运行（包括失败的）进试验台账。
8. **权限分离**（P6）：研究 agent 不能改引擎、关卡、风控与门槛配置，读不到锁箱数据。
9. **安全**：仓库是公开的——任何令牌、IP、账号、`config.json` 不得入库；MCP 只经隧道访问。
10. **实盘**：LLM 不进交易环路；默认只允许模拟盘下单；风控进程独立于策略进程。

## 6. 决策记录（2026-10-25）

| 编号 | 决策 | 理由 | 状态 |
| --- | --- | --- | --- |
| D1 | `contract_size` 必填，无默认值 | 默认 1 会让盈亏差几百到十万倍且无任何报错 | 已落地 |
| D2 | 跳空穿止损按开盘价；跳空越过 TP 按 TP 价 | 止损宁可更差；止盈不计跳空收益（保守） | 已落地 |
| D3 | 空头 SL/TP 按 Ask 触发 | 与 MT5 一致，换日点差扩大会扫空单止损 | 已落地 |
| D4 | Sharpe 按实测 bar 频率年化 | 5 天市场按日历年化高估约 18% | 已落地 |
| D5 | 锁箱改为全局单一固定 cutoff | 防跨品种泄露锁箱期信息 | 待 T2 |
| D6 | 点差改相对口径（按价格水平缩放） | 近期点差不能直接套用到价格低得多的早年 | 待 T3 |
| D7 | tick 按月分区存储 | 单文件刷新随历史线性变慢、内存爆 | 待 T4 |
| D8 | MCP 只监听回环地址，远程经隧道访问 | 仓库公开后主机地址已暴露 | 待 S1 |
| D9 | 新增 GitHub Actions 全量测试（windows-latest） | 每次推送自动验证 | 见 T8 |

## 附录 B：初始门槛（写入 `config/gates.toml`；P5 用基线策略校准后冻结）

| 关卡 | 指标 | 初始门槛 |
| --- | --- | --- |
| G1 | 样本内交易次数 | M5–M15 ≥ 300 笔；H1 ≥ 150 笔 |
| G1 | 平均每笔毛利 | ≥ 3 倍来回成本 |
| G1 | 净盈亏比（profit factor） | ≥ 1.2 |
| G2 | 成本放大 | ×1.5 仍为正期望；×2 的结果记录备查 |
| G2 | 参数邻域（每个参数 ±1 档） | ≥ 70% 的邻近组合净盈利 |
| G2 | 按年分段 | ≥ 70% 的年份盈利；单一年份贡献不超过总利润的 50% |
| G2 | 随机入场基准 | 夏普高于随机入场蒙特卡洛的 95 分位 |
| G2 | 买入持有基准（仅多头策略） | 夏普高于同期买入持有 |
| G2 | 去掉最好的 5% 交易 | 仍盈利 |
| G2 | 延迟一根 bar 执行 | 仍盈利 |
| G2 | 跨品种 | 通用逻辑在至少 2 个品种上为正 |
| G3 | walk-forward | 样本外夏普为正，且不低于样本内的 50% |
| G4 | Deflated Sharpe Ratio | 概率 ≥ 0.95（按台账中该卡家族的试验次数） |
| G5 | 锁箱 | 期望为正，指标落在样本外蒙特卡洛区间内 |

Deflated Sharpe Ratio 的计算见 Bailey 与 López de Prado（2014）*The Deflated Sharpe Ratio*。
