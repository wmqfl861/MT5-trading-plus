## 2. 专项审查（按审核指令逐项）

### 2.1 永久规则残留路径（双失效场景）——M1

三重回收（120 秒上限 → 10 分钟兜底任务 → finally）在**单层失效**时都成立：

- 脚本被硬杀（`Stop-Process`）：finally 不执行，兜底任务 +10 分钟删规则（前提见 M2）；
- Ctrl+C / 等待中出错：finally 执行，删规则 + 注销任务；
- finally 删规则失败但兜底任务在：FINALLY-ERROR 如实记录，规则由兜底在 10 分钟内回收（日志陈述此刻为真）。

**双失效洞在 STEP2 注册失败分支**：`Register-ScheduledTask` 抛错 → `$taskCreated` 保持 `$false`（**兜底任务不存在**）→ finally 删规则也失败 → `exit 1`。此时：

- **没有任何自动层会清这条规则**——exit 1 之后规则永久留存，唯一回收手段是注释帮助 `.EXAMPLE`（L48-50）里的两条人工命令，而该指引**不在运行时输出里**，操作员若不看 `Get-Help` 根本不知道要清；
- 更糟的是 L196 的 FINALLY-ERROR 日志**无条件**声称"兜底任务将在 10 分钟内自动删除它"——在此分支这是虚假陈述，操作员会等一个永不到来的自动回收，与"任何一层失效规则都会消失"的设计承诺相反。

修复（小 diff）：FINALLY-ERROR 消息按 `$taskCreated` 分支——未建兜底时改打"无兜底任务，请立即人工执行：Remove-NetFirewallRule -Name … / （如任务残留）Unregister-ScheduledTask …"，控制台+日志都出。

### 2.2 `-Program` 是否真的只拦终端进程——符合

规则唯一、按程序路径限定（`Resolve-Path` 规范化后的 `terminal64.exe` 全路径）、方向仅 Outbound。其它进程（三进程本体、Python、supervisor）出站完全不受影响；Windows 防火墙不过滤环回，Python 网关与终端的本地 IPC 也不受影响——演练语义（终端↔交易服务器断、网关活着走重连路径）成立。规则未限定 Profile/协议/端口，作用面仍然只收敛在该 exe 路径上，无误伤面。规格"绝不拦整机"满足。

### 2.3 探测歧义拒绝——符合且方向保守

零候选 → throw 必填；多候选 → throw 必填（不默认取第一个）；显式路径再过存在性 + 叶子名 `terminal64.exe`（`-ine` 大小写不敏感）双检。探测列表用环境变量不硬编码本机路径（卫生测试同口径核过）。探测环境变量在 32 位 PowerShell 下语义会偏（ProgramFiles 指向 x86），但探测失败方向是"必填报错"，最坏是要求显式传参，安全。

### 2.4 语法与可运行性——独立验证通过

本机 PowerShell 5.1（5.1.22621.1037）`Parser::ParseFile`：**0 错误 0 警告输出**；`[scriptblock]::Create` 编译成功。`[Security.Principal.WindowsIdentity]` / `[Security.Principal.WindowsBuiltInRole]` 类型字面量靠 PS 自动补 `System.` 前缀解析，标准写法。实现方自报的"Parser 零错误"可信。

### 2.5 兜底任务 Principal 能否无人登录触发——M2

`New-ScheduledTaskPrincipal -UserId $winIdentity.Name -LogonType Interactive -RunLevel Highest`（L172）＝任务计划程序"只在此用户登录时运行"。要点：

- **断开的 RDP 会话（disconnect 未 logoff）仍持有登录会话**，Interactive 任务一般仍能触发——真正失效条件是**注销**；
- 周六演练的现实编排恰恰是高危场景：演练中脚本被杀 → 操作员收尾注销、让 PaperSoak 无人值守自跑 → +10 分钟触发时无交互会话 → 触发错过；靠 `-StartWhenAvailable` 顺延到**该用户下次交互登录**（可能周一）——期间终端出站静默被拦，soak 全程报废（所有组件无限 DISCONNECTED / rc=75），正是本演练要证明"有界"的反面；
- 兜底任务的存在意义就是"主人已经不在场"，其触发条件却依赖"主人在场"，设计自相矛盾。

修复建议：`-UserId "NT AUTHORITY\SYSTEM" -LogonType ServiceAccount -RunLevel Highest`——无需密码（SYSTEM 账户注册不存凭据）、无头触发、SYSTEM 删防火墙规则无障碍；现有预检 + `-Force` 覆盖流程不受影响。若不改代码，则必须有书面运维规定：演练开始至结束后 ≥10 分钟内操作员保持交互登录不注销。
