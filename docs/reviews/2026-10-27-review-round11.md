## 第三部分：修改方案（摘要；细节见蓝图 v4 与计划）

1. **重新定位基线**：
   - 六张基线卡改称"标定样品"，只用于校准关卡、成本、引擎与实盘链路，不作研究候选；
   - 三张 v2 卡撤回：没跑过的不计入试验次数；跑过的如实计入；撤回记录写进候选登记表。
2. **选题流程**：候选登记 → 预筛 → 研究轮次预注册 → 开卡 → 关卡。预筛有五条硬条件：
   - 文献含发表后或样本外证据，并已检索过反驳；
   - 持仓 ≥ H1；
   - 事前成本检查：每笔预期毛利 ≥ 3 倍来回成本；
   - 在现有数据上检验力 ≥ 50%，否则进"待数据"队列；
   - 补一种组合里还没有的机制。
3. **研究轮次预注册**（看结果之前定下）：
   - 本轮最多 3 个新谱系；
   - 跨谱系试验次数按项目级计算；
   - 本轮最多用几次锁箱（D16）；
   - 推进规则；
   - 低频策略的评估方式。
4. **关卡 v3**：
   - 一个预注册的主检验：walk-forward 拼接样本外收益的单侧检验，按项目级试验次数校正；
   - 少量否决项：数据卫生、成本 ×1.5、延迟一根 bar、多头策略相对买入持有的超额；
   - 其余检查改为诊断，只报告不否决；
   - 用正负对照标定整套关卡：联合误报率 ≤ 5%，并如实报告夏普 0.5 与 1.0 时的联合检出率；
   - 须用户批准后才冻结。
5. **低频事件模式**：以事件为单位评估，样本量要求来自检验力计算，而不是固定笔数；用事件时间随机化做零假设、用植入事件效应做正对照来标定。
6. **数据延长**：外部数据把 XAUUSD、EURUSD 拉长到 2005 年前后，USTEC 用纳指 100 指数日线，BTC 从 2014 年起。入库前先核对价格口径、时区与夏令时、与 MT5 重叠期的一致性，以及历史点差。
7. **确认性证据**：研究段只用于探索。确认靠两样：锁箱（一次性，预算 D16）和前向样本（候选策略在影子盘或模拟盘上运行 6–12 个月）。
8. **首批候选只登记、不直接开卡**：月末效应（USTEC）、月末对冲调仓（USTEC 当月涨跌 → EURUSD）。两者都要先补发表后的证据，并等低频事件模式标定完成。
