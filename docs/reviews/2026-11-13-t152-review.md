## 5. 问题分级

**阻塞 / Major：无。**

- **Low-1（健壮性，建议加固）**：`nights_memo` 键 `(id(rule), entry_ts, exit_ts)` 不持 rule 强引用——若某调用路径的 `swap.rule(symbol)` 每次返回**新**对象且被 GC 后 id 复用，理论上可命中陈旧 nights。当前代码库**无触发路径**：`randomization_test` 的全部调用方（`scripts/bt.py`、`scripts/gate_calibration.py`）传生产 `Costs`，`SwapModel.rule` 返回 `_per_symbol` dict 内稳定实例（costs 整个调用期存活）；唯一每次新建 rule 的路径（`robustness.ScaledCosts._ScaledSwap`、`gate_calibration._ScaledCosts`——`dataclasses.replace` 只改 long/short_per_day）仅进 `event_returns` 公共 API（`nights_memo=None` 不缓存），且 charge_nights 所读字段（charge_weekdays/triple_weekdays/charge_local/charge_tz）不受其缩放影响。建议：键直接用 `(rule, entry_ts, exit_ts)`——`SwapRule` 是 frozen dataclass 可哈希，值语义天然免疫 id 复用。
- **Low-2（健壮性）**：`_normalize_days` 按对象身份记忆化的纯度前提是输入不可变。`DatetimeIndex` 满足；但 `month_end_events`/`london_fix_events`/`fomc_calendar_events`/`randomization_test(trading_days=...)` 类型上不拒绝可变 list——若调用方传入同一 list 对象并在两次调用之间原地修改，会命中陈旧缓存。当前全库调用均传 DatetimeIndex 或临时构造对象，无此用法。建议 docstring 标注输入须不可变，或对非 Index 输入跳过 memo。
- **Low-3（边界）**：`tags.to_numpy()` 与 `tags.iloc[i]` 在**含 NA 的箭头字符串列**上的标量表示可能不同（None vs pd.NA），进入 `source_costs` 后分支不同。现网与测试的全部 `_research_source` 列均为完整字符串（R3 形混合 ext/mt5 标签对拍逐位一致），不触发。若未来引入 NA 标签需先钉等价性。

**观察（不计问题）**：`_DAYS_NORM_MEMO`/`_DAYS_STRATA_MEMO` 为模块级全局——CPython GIL 下 dict 读写原子，多线程最坏丢一次缓存不致错值；容量 8/65536 触顶全清策略正确性无损。
