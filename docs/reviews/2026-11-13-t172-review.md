### 2.4 glob 与 pytest 收集的等价性（遗漏面排查）

旧 CI `python -m pytest`（无参数）按 `pyproject.toml` 的 `testpaths = ["tests"]` 递归收集，默认 `python_files = test_*.py`。选片命令用**非递归** `glob('test_*.py')`。实测：

- `find tests -type d`：除 `__pycache__` 外 tests/ 下**无子目录**（扁平），`-mindepth 2 -name "test_*.py"` 无结果 → 非递归 glob 与递归收集等价；
- 全仓库无 `*_test.py` 等其它命名模式文件；tests/ 之外无 test_*.py；
- pytest 配置无 `norecursedirs`/`python_files` 定制（pyproject 仅 `pythonpath=["src"]`、`testpaths=["tests"]`）。

结论：选片面 == 旧收集面，无遗漏。

## 3. 选片命令边界审查（方法 3）

- **排序稳定性**：`sorted(..., key=lambda p: p.name)` 是 Python 字符串码点序（ordinal），与 OS locale / `LC_ALL` 无关（Python str 比较不走 locale）。当前 149 个文件名全部 ASCII、全小写、无空格、无重复（实测 non-ascii: []、uppercase: []、含空格: 0），码点序在任何 locale 下唯一确定 → CI（windows-latest）与本地不存在排序分歧面。双解释器交叉验证（venv Python 与系统 Python 3.12.10）四片清单逐文件一致。
- **新增文件自动入片**：选片在 job 运行时 `glob` 当前 checkout，无维护清单；数学上 sorted 列表索引 i 唯一 → `i%4` 唯一归属一片 → 并集恒为全集、两两恒不相交。成立（声明验证通过）。
- **空分片边界**（Info 级）：仅当（去 hygiene 后）文件总数 ≤3 时某片会为空，此时 pwsh `$shardFiles` 为空、`python -m pytest -q -p no:cacheprovider` 无路径参数会按 testpaths 回退全量收集——后果是**重复**而非遗漏，且当前 148 文件远不触发。纯边界记录，无需修改。
- **pwsh 传参**：选片行在 pwsh 双引号串内无 `$`/反引号插入风险，`'\n'` 以字面量传入 Python 由其解释；文件名无空格，数组展开为多个 argv 安全。pwsh 实测 `$shardFiles.Count` 输出 37。
