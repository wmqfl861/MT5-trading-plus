## 必改

### F1 概率表的平均净收益收缩公式错误（`src/mt5quant/prob/tables.py` `_aggregate`）

- 现行：r̄_o = (Σr_o + m·r_base_o) / (n + m)。分母混入了其他结局的计数，大样本时 r̄_o 趋近 p_o × 条件均值，期望值被系统性压低。
- 实验：一格与基准分布相同（赢 400 笔 1.95R、输 550 笔 −1.05R、到期 50 笔 0.15R，m = 100）：

| 量 | 现行 | 应为 |
| --- | --- | --- |
| r_win | 0.886 | 1.950 |
| r_loss | −0.620 | −1.050 |
| EV（z = 0） | +0.014R | +0.210R |

- 改为按结局的伪样本数收缩：r̄_o = (Σr_o + m·p_base_o·r_base_o) / (k_o + m·p_base_o)；概率 p̂_o 的公式不变。
- 已有测试只检查概率、不检查平均收益，所以没发现。

### F2 purge 跨周末漏剔（`src/mt5quant/prob/labels.py`）

- 现行按"触发时刻 + (K+2) × 周期 ≤ train_end"判断。周末和节假日缺口使 K 根 bar 的实际跨度远大于 K 个周期，标签会用到 train_end 之后的数据。
- 实验：周五 18:00 的触发、K = 24、train_end 设在周六 21:00，触发被保留，但它的标签用到了下周一 19:00 的 bar。
- 改为按 bar 下标：保留条件为 t+K+1 < len(bars) 且 bars.time[t+K+1] < train_end。已有测试用的是连续合成序列，没有缺口。
- 影响：违反铁律 21；在 walk-forward 拟合（T73）之前必须修好。

### F3 "接近价位"定义过严（规格错误，`docs/blueprint-p-line.md` §2.1 与 `situations.py`）

- 原规格：前 M 根每根都离价位 ≥ D 个 ATR，本根进入 ±d 个 ATR。这等于要求本根比上一根至少冲高 (D − d) 个 ATR，事件稀少，而且只选中"一根大阳线撞上价位"。
- 实验（3 万根随机游走 H1，网格 5.0，M = 24、D = 1.0、d = 0.25）：原定义只有 24 个阻力事件，事件 K 线比上一根高点中位冲高 1.50 个 ATR。
- 改为：本根进入触及带；前 M 根都在触及带之外且位于价位同侧（阻力：high_j < L − d·ATR_j；支撑对称）；其中至少一根离价位 ≥ D 个 ATR。同一实验下得到 117 个事件，中位冲高 0.89 个 ATR。
- 样本量是 P 线的瓶颈（蓝图 §3.4），这一处影响很大。
