# MT5 量化系统 P0收尾 / P1 / P2 / P3-A层 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按用户《MT5量化交易系统开发计划》完成本轮迭代：P0 收尾（品种参数快照、每策略 magic、服务器时钟测量）、P1 数据仓库收尾（tick 存储、质检、重采样校验、锁箱、每日调度）、P2 成本模型与可交易性审计、P3 的策略接口 + A 层向量化回测引擎 + 标准报告 + 截断测试工具。

**Architecture:** 现有三包不变职责：`mt5gw`=网关（实盘执行原语，计划中 live/ 的底座）、`mt5data`=数据仓库（计划 data/）、`mt5mcp`=远程数据服务。新增 `mt5quant` 研究包（计划 costs/backtest/strategies/）：`mt5quant.costs`、`mt5quant.strategies`、`mt5quant.backtest`。研究侧读 parquet 直连（不经 MCP），与实盘共用同一份策略代码。

**Tech Stack:** Python 3.12（`.venv`）、pandas / numpy / pyarrow / duckdb（均已装，**不新增第三方依赖**；zoneinfo 为标准库）。

**Spec:** 用户附件《MT5量化交易系统开发计划》（P0–P3 部分）；本仓库 `docs/superpowers/specs/2026-10-22-mt5-gateway-design.md`、`2026-10-22-mt5data-mcp-design.md`。

**基线：** git `d930b9e`，154 tests 全绿。

## Global Constraints（所有任务隐含遵守）

- 内部时间一律 UTC：本库既定约定是"贴 UTC 标签的 naive datetime（实为服务器时间）"；涉及交易时段（America/New_York 等）时用 `zoneinfo` 显式换算，结果仍转回 naive-UTC 表示。
- 只用已收盘 K 线计算信号；信号在 bar 收盘产生、下一根 bar 开盘成交。
- K 线按 Bid：多单按 Ask 入场、Bid 出场；空单相反（引擎按 half_spread 模型实现，见 T6）。
- 同一根 bar 内同时触及止损和止盈 → 止损先触发。
- 回测与实盘共用同一份策略代码：策略模块只实现统一接口，不做 I/O、不持有全局状态。
- 回测可复现：报告带 manifest（git 提交号、数据快照哈希、参数、成本模型版本）。
- 策略参数 ≤4 个、网格总组合 ≤100（接口层校验拒绝）。
- 不新增第三方依赖；不修改 `tests/fakes.py`、`pyproject.toml`、`README.md`、`.gitignore`（集成时统一处理）。
- **只改各自任务 Files 清单内的文件**（并行开发，越界即冲突）；新测试的假件放独立新文件，不进 `tests/fakes.py`。
- 不执行任何 `git` 写操作（不 commit/add/checkout）；集成时统一提交。
- 测试命令：`./.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider tests/<file>::<test> -v`（Git Bash，正斜杠）。
- 代码风格与现库一致：中文 docstring、fail-fast 如实抛错、frozen dataclass、原子写复用 `mt5data.store` 的锁模式。
- 真机脚本只保证"可运行+单元测试过"：子代理**不得**尝试初始化 MetaTrader5 真连接（终端被其他进程占用会互相干扰）。

## Review Focus（最可能咬人的五类输入，各自测试落在归属任务）

1. **前视偏差**（负向 shift、用了信号 bar 收盘价成交）→ T6 截断测试 + "下一根开盘成交"精确断言 + 故意埋前视的策略必须被查出。
2. **夏令时换算错误**（周末缺口在 10/25、11/1 切换周被误判为异常，或反之）→ T3 sessions 测试钉死 2026-10-25（欧洲）与 2026-11-01（美国）两个切换周的真实边界时刻。
3. **tick 增量损坏历史**（refresh 后出现重复/乱序 time_msc、或接续无法证明）→ T2 用含重叠页、乱序页、缺边界页的假件各测一条。

5. **成本方向/口径错误**（滑点变成有利方向、half 与 full spread 混用、三倍隔夜费算错方向）→ T5/T6 全部用手工可复算的数字断言（正负号逐项钉死）。
