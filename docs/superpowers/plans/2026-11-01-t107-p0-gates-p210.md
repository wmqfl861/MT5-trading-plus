## 模块 A（阶段 1+2+4 的代码）：研究门禁与实验指纹

新文件 `src/mt5quant/research/gate.py`（P 线新增，不改既有接口）：
1. **ResearchGate 四态**：`research_gate(*, method_id, calibration_ok,
   sample_evidence, fingerprint) -> GateResult(status ∈ {PASS, FAIL,
   INSUFFICIENT_DATA, NOT_RUN}, reasons[])`——
   - NOT_RUN：方法未登记或 calibrating；
   - FAIL：方法 adopted=False（含 failed_cluster_control/not_adopted_*）
     **或** 标定状态失败——**校准失败必须阻断**（放行通道不存在）；
   - INSUFFICIENT_DATA：sample_evidence ∈ {lower_bound_only, uncalibrated}
     或 days 不足；
   - PASS：仅 method adopted=True 且 evidence=calibrated_sufficient 且
     days≥门槛——**当前仓库永远到不了 PASS（方法全 not adopted）**，
     这是诚实状态，测试断言之。
2. **ExperimentFingerprint**：单函数 `experiment_fingerprint(*, strategy_ref,
   card, model_dict, bars_meta, cost_version, sessions_sha, params, features,
   evaluator_sha=None)
   -> {run_id, sha256, components}`——**六维显式组件**：代码（策略闭包）/
   数据（bars_meta）/参数（params）/特征（features）/成本模型
   （cost_version+sessions_sha）/评估代码（evaluator_sha——复用 bt.py
   _p1_evaluator_sha 或等效；缺省 None 时组件记 None 并在 components 标注
   "评估代码未绑定"，不冒充覆盖）；任一必填组件缺失→ValueError 不静默
   空串（P2-07 教训）。
3. **阈值固化守护**：`ACCEPTANCE_CONSTANTS` 只读快照（lb_z/threshold_mult/
   min_cell/prior_strength 的**现行值**与文件哈希），gate 返回中携带——
   消费方可断言未漂移；docstring 写明"按候选结果反调验收阈值=违规"。
4. bt.py 接线（最小）：`bt prob round-report` 在现有方法门标注旁输出
   ResearchGate 四态一行（不改 exit code 语义）；既有行为零变化。
5. 测试：四态转移表（显式优先序：按所列顺序首个命中；calibrating 且
   登记在册→NOT_RUN 优先于 FAIL；INSUFFICIENT_DATA 的 days 阈值来源=
   sample_size_evidence 同一数字）、方法全 not_adopted → 永不 PASS、
   指纹敏感性（**六维各自**变化→hash 变：代码/数据/参数/特征/成本/评估
   代码）、缺失组件拒绝、阈值快照与现行常量一致。

## 模块 B（阶段 3）：P2-10 统计覆盖研究——预注册设计（结果前冻结）

### 研究对象（现行估计器，只读不改）
`ProbTable.fit` 收缩（m=prior_strength 伪计数向 base rate）+ `_se`（Wald：
收缩后 p̂、**原始 n**）+ `ev_lower`（只传播 p 的不确定度；r 无不确定度项；
概率不截断）+ **真实决策层=level_decision.generate_signals 的内联循环**
（复刻其语义：候选含局面维度（同 bar 跨局面共存）、过门槛取 EV 最高、
并列 (sit,action,side) 字典序、**方向冲突弃权**（过门槛双向并存→不做——
只降低开仓，对误开放是实质影响）；decision.py 的 choose() 是无生产调用
的旧接口，不作为研究对象）。

### 预声明估计器对照（不因结果调任何阈值）
- E0 现行（Wald@收缩 p̂/原始 n）；
- E1 Wilson 下界（有效计数 k+m·p_base, n+m）；
- E2 Clopper-Pearson 下界（同有效计数）；
- E3 Jeffreys 下界（同有效计数）。
三替代的 p 界进入 ev_lower 的方式（预写）：win 取下界、loss 取上界、
time=1−前两项（同现行不截断口径）；有效计数=(k+m·p_base_o, n+m)。
r 的不确定度全部不传播（与现行同口径——单独披露为局限，不改对照集）。

### 数据生成（合成；独立交易日为统计单位）
- 真值：每格 (p_win,p_loss,p_time) 由 Dirichlet；r 由正态（均值/方差扫描）。
- **同日重叠**：一日多触发共享当日结局（labels 同口径）——行数≠有效样本，
  有效单位=日；DGP 按日生成再展开为行。
- **共享 base rate**：全部格收缩向同一基准（现行 fit 的实际形态）。
- **缺失特征**：按预写比例的特征缺失→落父格/基准（对现行行为的复刻）。
- **K 跨 session 边界**：标签口径按现行 labels（time 出场/截尾），模拟
  session 边界两侧的触发占比扫描。
- **多重比较**：真实决策层在全部（局面×动作×方向）过门槛候选中取最大
  EV 下界（同 bar 可跨局面）——false-open 按决策层口径计量（含选择效应
  与方向冲突弃权）。
- 条件矩阵：父格 n∈{1,2,99,100}（**单位=独立交易日**；估计器输入按现行
  行为复刻——格内 n=行数是研究对象本身，研究侧不替它改口径）× 结构
  {混合, 父格全胜, 父格全负, **动作级全胜/全负**（经验基准 p̂=1/0——
  SE=0 病灶的唯二触点：base=None 层与收缩格 p̂≡1；含 lookup 回退到
  基准的触发）} × base rate∈{0.34,0.1,0.5, **0.0, 1.0（动作级边界档）**}
  × 同日簇大小∈{1,3,10} × 特征缺失∈{0,0.3} × K 跨界∈{无,50%}。

### 预写验收标准（跑前冻结；不达标→报告如实+可提出版本化估计器变更提案，不直接改产品）
1. **覆盖**：E0 的 EV 下界对真 EV 的经验覆盖（P(EV_lb ≤ EV_true)）在全部
   预写主条件 ≥95%（名义保守性成立）；**任何条件 <80% 判"保守性不成立"**
   （红牌，提案义务）。**预判锚（跑前写死，报告期不得临场解释）**：
   lb_z=1.0 单项名义≈84%；m=100 收缩使 Wald SE（按原始 n）高估收缩估计
   实际波动约 (n+m)/n 倍（n≈100 时有效 z≈2）——混合档覆盖预期 >95%；
   动作级全胜/全负档 SE=0 → 覆盖预期塌向 ~50%（红牌候选，若兑现即
   触发版本化估计器变更提案）。
2. **误开放率**：true EV ≤ 0（扣成本后无优势）时决策开放的概率——主条件
   ≤5%；>10% 判红牌。
3. **决策稳定性**：同一真值两次独立重抽（同 n）决策一致率报告（无硬门，
   报告项）。
4. **对照**：E1/E2/E3 与 E0 的覆盖/误开放/平均下界宽度并列报告；不因
   对照结果改 E0 阈值。
5. 失败案例：全部红牌条件列出（真值/样本/决策/下界），保留原始数据。
6. 单位纪律：**有效样本=独立日**——重复行不得伪增 n（DGP 与计量都按日）。
