# D61 V2-A 隔离计算核 Implementation Plan

> **For agentic workers:** Use subagent-driven-development in the assigned isolated worktree; controller assigns independent code review and integration. No nested agents.

**Goal:** 实现可实际调用的纯内存日等权 V2-A 下界计算核，用固定人工样例验证正确性，为 D61 后续研究提供已审核的实现基础。

**Architecture:** 新增一个标准库模块，不接入现有概率表、策略、模型、CLI或研究运行。日聚合与收缩采用 Fraction，半径采用固定私有 Decimal 上包围，输出有限且保守的 binary64。只增加独立测试和简短模块说明。

**Tech Stack:** Python 3.12、stdlib dataclasses/fractions/decimal/math、pytest；无新增依赖。

**Spec:** [本次独立范围裁定](../../reviews/2026-11-05-d61-v2a-scope-review.md)，[归档设计§2/3.1/9](../../research/d61-estimator-v2-validation-design-2026-11-03.md)。本次裁定的具体三条件优先于原请求的歧义。

## Global Constraints

- 仅人工内存样例，无随机生成器、真实数据、标签器、fit、覆盖率研究或完整2304条件矩阵；不宣称研究PASS。
- 固定m=100、cell/parent可见日门100、delta_c=1/900、lb_z=1；不暴露调参入口，不加开门epsilon。
- 不改现行tables/decision/labels/策略/冻结配置或旧报告，不导出到产品概率接口，不连接MT5/账户/运行状态。
- 作者仅修改本任务三文件，精确[P]提交，不推送、不派代理、不自填approved_by。主会话独立审核后统一整合/全量/推送/核对CI。
- 保持未知为None、越界拒绝、输入不变；失败不截值、不调整支持或精度。

## Review Focus

- 动作池跨局面同日先平均，不把(parent,day)或复制行当更多独立观测。
- 目标计划日与中心可见日不同，全缺失不增加资格；空目标也要先完整验证输入/支持。
- 收缩条件收益按实际分母判None，不能将局部未出现误当全局未知。
- ln/sqrt上包围和最终向下float转换必须有独立误差界oracle；外部Decimal上下文不能影响结果。
- 冷导入仅定义工程函数，不引入研究、MT5、标签/拟合或文件数据访问。

### Task 1: 计算核、固定样例和模块说明

**Files:** Create `src/mt5quant/prob/d61_v2a.py`, `tests/test_d61_v2a.py`, `docs/research/d61-v2a-kernel-2026-11-05.md`。

**Interfaces:**

```python
@dataclass(frozen=True)
class PlanRow:
    day_id: int
    situation: str
    action: str
    feature: str
    outcome: str | None
    gross_r: int | float | None

estimate_v2a(rows, *, query, support, lb_z=1.0) -> V2AResult
```

`rows`为PlanRow序列，`query=(situation,action,feature)`；support映射win/loss/time到两个builtin int/float端点。固定结局顺序win/loss/time。作者可为输出定义简洁frozen dataclasses，但须公开记录并提供：lower、guard、radius、mean_w、center、选层(cell/parent/action/none)、目标计划日数及每层row/planned-day/visible-day/outcome/missing计数、收缩概率和条件收益(None保留)、动作池q/v。数值诊断输出float或None，整数计数保持int，不让诊断回流计算。无PASS、批准、模型或交易信号输出。

- [ ] 先写手算/拒绝测试，在缺少实现时保存准确RED；然后按顺序最小实现验证。不得用全套缺模块错误冒充后续逻辑反例。
- [ ] 严格校验所有行、查询、支持和lb_z。day_id非负int非bool；S1/S2、A1/A2、f0/f1/na；outcome与gross_r同时None为缺失，否则结局win/loss/time和有限builtin数字。query仅S1:A1/S1:A2/S2:A2×三特征。相同(s,a,day)特征冲突拒绝。支持键恰三项、a_o<b_o、可见收益在对应闭区间；不推断结局、不从ID间隙补日。
- [ ] 全部数值按精确Fraction解释；大整数直接Fraction，不先math.isfinite转float丢精度。全局a必须精确有限binary64（按独立裁定检查），此校验先于空输入返回；其他端点不因此收紧。不能产生有限输出则ValueError。
- [ ] 每层先选行再按全局日聚合：目标W缺失填a，以当日全部计划行作分母；中心Y/Z只用可见行且共用当日可见数。cell/parent各≥100可见日才可用，否则非空同动作池为中心，池跨局面不能跨动作。m仅用于中心，不增加n_eff。
- [ ] 严格按归档k/s/q/v及收缩公式计算。基准层中心为日等权均值，不能先平均父格。条件收益分母0才None、贡献0；局部未出现但池有时仍有可知条件收益。D=0时lower=guard=a、mean_w=radius=None，中心可有诊断；D>0即使无中心也计算radius/guard，lower=a。
- [ ] 私有显式80位Decimal上下文，固定Emin/Emax/clamp及traps，允许Inexact/Rounded，ln/sqrt HALF_EVEN后next_plus；Fraction转Decimal的商ROUND_CEILING。精确整数构造、同一context next_plus、Fraction h_up与下界，严格遵守范围裁定完整链。不继承global/default context；异常转ValueError。lower/guard向下、radius向上float转换，有限性检查，不使用math.log近似或结果依赖精度重试。
