## 一、预注册设计（结果之前冻结；实现/标定不得偏离，偏离即报告作废）

### 方法标识与统计量
- `method_id = "cluster-permutation-v1"`（prob_mode.METHOD_REGISTRY 登记
  status=calibrating；标定通过才 adopted）。
- 统计量不变：触发组日赢率均值 − 随机组日赢率均值（日聚合 Δp，D52）。
- p 值：Monte Carlo 置换 (1+k)/(1+B)，B=10,000。

### 簇构造（只看时间/可用性，不看赢输）
- 交换单位=**簇**：把 real+null 两组合并的**触发日**按时间邻接聚簇——
  相邻触发日间隔 ≤ `CLUSTER_GAP_DAYS=10` 个日历日归同簇；间隔更大开新
  簇（覆盖审核测试的 10/20 交易日簇结构；跨月不拆）。
- 簇内日数不限；重叠依赖区间（同簇相邻日）天然保留。

### 零假设变换（整簇交换）
- 每次置换：把全部簇随机重分成两组，统计量按日重算（簇内各日随簇走
  ——自然带簇权重，不把不等大小簇当等权天数）。
- **组簇数定义（混合簇规则，预写写死）**：合并聚簇后混合簇大量存在
  （实测约占一半），"两组簇数"按**簇内 real 日占比多数归属**计数
  （real 日数 > null 日数 → 计 real 簇；< 计 null；**平局计 real**
  ——确定性规则）；重分时两组目标簇数 = 该多数归属计数。每次重分后
  两组日数不守恒（最大簇可占 ~20% 日数）——**披露进审计输出**
  （两组日数分布随重分记录）。
- **条件可交换依据**（审核 §4.3 步骤 3 要求）：(i) 成簇对照下 real
  与 null 是同一冻结触发集的独立刚性平移——两侧簇大小/形状分布按
  构造相同，簇级标签近似可交换；(ii) 正式 P1（real 成簇 vs 桶匹配
  随机 null）下簇级可交换是**结构性假设**——对照只验证对称情形，
  适用边界在报告 v4 显式声明（CI 是条件模拟误差，不覆盖所有市场）。
- real/null 重叠依赖：合并聚簇后混合簇整簇同走——不存在跨组拆簇。
- 括注修正：CLUSTER_GAP_DAYS=10 为**日历日**（≈7 交易日），不字面
  覆盖审核模拟的 10/20 交易日簇；跨簇残余相关由 cluster 相位实测。

### 最少交换单位与分辨率
- 任一组簇数 < `MIN_CLUSTERS_PER_GROUP=5`，或组合数 C(n,k) 的最小可达
  p > 0.001 → **不可检验**（返回明确状态，不打碎簇凑样本）。
- 输出审计：簇数/簇大小分布/最小可达 p/接受率（§4.3 步骤 4 可审计
  输出要求）。

### 匹配与资格
- 消费批 2 的 EligibilityContext（同一资格判定先行，real/null 同规则）；
  randomize_triggers 的合格 bar 池匹配（NY 小时/星期/ATR 档）不变——
  本方法只改 **p 值的置换单位**，不改 null 的构造方式。

### seed 与分离
- 探索（单元测试/合成调参）与验证（正式标定）分离：正式标定 seed 基
  （S_NEG=20261101, S_HOLM=20261102, S_POS=20261103, S_CLU=20261104,
  S_BRI=20261105）一次写定；**任何相位失败不得换 seed 重跑**（失败即
  不采纳，升级选项=月块自助 D42 原法，不在本批）。

### 预写验收标准（全部通过才采纳；任一失败→不采纳、报告如实、升级）
1. **neg 单假设**：n∈{500,1000,2000}（名义）× **1,000 种子**/条件：
   **硬门=逐条件点估计 FPR≤5%**（名义 α 不放宽、不跨条件平均——与
   T75/v2/v3 判定口径连续）；CP95 单侧上界为报告项。**一次性两段
   升级规则**（预写写死，非边看边扩）：首段 500 种子；点估计 ≤5% 而
   CP 上界 >5% 的条件，追加预定第二段至合计 1,000 种子，以合计
   CP 上界判定，终局不再扩；首段即两项皆过者直接通过。
2. **neg-holm**（12 假设，n=1000）× **500 种子**：联合 FPR 点估计
   ≤5%（硬门）；CP 上界报告项+同一两段规则（→1,000）；
3. **成簇负对照**（P2-06 修复后的平移机制）：w3 与 w7 各 **500 种子**，
   各自点估计 FPR≤5%（硬门）+两段规则（→1,000）；
4. **pos 功率**：Δp∈{.02,.03,.05}×n∈{500,1000,2000,4000}×100 种子：
   报告功率点估计与区间；**锚点资格格**（用于 calibrated_sufficient）
   要求该格功率的 CP95 **下界** ≥50%（100 种子需 ≥59 拒，即真功率
   ≳60% 才稳定资格——"证明充分"方向的本意，保留）；预期 dp0.03@2000
   （旧方法 51-53%）大概率失去资格、0.03 档锚点升档或降级，属合法
   结果；
5. **brier**：200 种子，现行两条标准不变（与簇方法无耦合，作为回归）；
6. **输入/几何**：P2-06/07 机制的单测保持全绿（disjoint/容差/桶审计/
  manifest 绑定）；
7. B=10,000；p=(1+k)/(1+B)；manifest v2 完备集与分片指纹校验通过。
