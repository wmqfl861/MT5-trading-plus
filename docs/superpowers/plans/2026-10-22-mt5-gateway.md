# MT5 网关（基石）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建成一个 Python 网关库，独占与本机 MT5 终端的通信，向策略层提供品种目录、行情、账户、交易四类能力，并附带一条跑通全链路的模拟盘冒烟验收。

**Architecture:** 单一 Python 包 `mt5gw`，分层为 连接（锁+重连）/ 领域服务（symbols、market、account、trading）/ 门面（MT5Gateway）。MetaTrader5 官方包是唯一外部依赖，通过构造函数注入（`mt5_module=None` 时才真实 import），因此全部单元测试离线跑在假 mt5 模块上；只有 Task 9 的验收碰真终端。

**Tech Stack:** Python 3.12（64 位）+ venv；依赖仅 `MetaTrader5`（运行）与 `pytest`（开发）。

**Spec:** `docs/superpowers/specs/2026-10-22-mt5-gateway-design.md`

## Global Constraints

- 终端路径默认 `C:\Program Files\MetaTrader 5\terminal64.exe`（实测在跑、模拟盘登录中）
- 网关内禁止任何策略逻辑；SL/TP 只透传，绝不自动添加
- 实盘保险丝：账户 `trade_mode` 为 REAL 且 `allow_live_trading=False` 时，一切交易调用必须先抛 `LiveTradingBlockedError`，`order_send` 不得被触达；解锁仅靠 config 显式开启
- 错误如实上报：不吞、不静默返回空；mt5 调用返回 None 时按各域规则转成异常或空集（positions/orders 的 None 视为空集并文档化）
- 所有对 MetaTrader5 包的调用经 `MT5Connection.call` 串行化（一把 RLock）；对上层呈现线程安全
- 行情为同步穿透取值，不缓存、不轮询；本地不落任何历史库
- 品种目录不提供按星期时段表（包取不到），README 注明缺失
- 时间戳约定：包返回的秒/毫秒用 `datetime.utcfromtimestamp` 转成 naive UTC 标签的 datetime（实为服务器时间），README 写明
- 依赖装 venv（`.venv/`），不污染系统；Windows + Git Bash 环境，命令一律写全路径

## Review Focus

1. 终端在跑但掉线/重启后（`terminal_connected()` False 或调用返回 None）→ `call` 自行重连一次，仍失败抛 `NotConnectedError`，绝不把 None 漏给上层 → Task 4 测试
2. 实盘账户 + 保险丝关 → 交易调用在触达 `order_send` 之前被拦（fake 计数 order_send==0）→ Task 7 测试
3. 券商不支持所选 filling mode（retcode 10030）→ 从 `symbol_info.filling_mode` 位掩码选首个受支持模式（FOK→IOC→RETURN）→ Task 7 纯函数测试
4. 市场关闭/品种禁交易（retcode 10018/10017）→ `TradeRejectedError` 带可读消息，非静默成功 → Task 3 映射 + Task 7 测试
5. `copy_rates/copy_ticks` 对未入 Market Watch 或无历史的品种返回 None → `DataUnavailableError` 携带 `last_error()` 内容 → Task 5 测试

- Produces: `TradingService(conn, config, account, symbols, mt5_module)`：
  - `market_order(symbol, side, volume, *, sl=None, tp=None, deviation=20, comment="") -> OrderResult`
  - `pending_order(symbol, side, kind, volume, price, *, sl=None, tp=None, comment="") -> OrderResult`（kind 为 "limit"/"stop"）
