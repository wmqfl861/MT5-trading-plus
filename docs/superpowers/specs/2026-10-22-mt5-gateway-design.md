# MT5 量化系统·基石（数据与交易网关）设计

日期：2026-10-22
状态：待用户批准

## 意图与为什么

用户要构建一个通过 MT5 交易的量化系统，整体分两段：

- **基石（本文档范围）**：一个 Python 网关层，独占与 MT5 终端的一切通信，向上（策略层）提供全部行情、账户信息和交易执行能力。
- **策略段（以后另行设计）**：跑在网关之上，晚点再说。

用户最初方案是"自写 EA 做数据桥"，经讨论改为 MetaQuotes 官方的 MetaTrader5 Python 包：官方维护、免自建通信协议、所需能力（全品种行情/账户/下单）全覆盖。网关仍保持独立分层，将来若需跨机部署或换语言，可把这一层替换为 EA 桥而不动策略代码。

核心原则（用户定的）：**桥里不夹任何策略逻辑，桥与策略只交换数据。**

## 目标

网关对上暴露四类能力：

1. **品种目录**：全部品种列表及各自规格——点值、点差、合约大小、最小/最大交易量、步进、交易状态（trade_mode、当前能否交易）、保证金货币等。注：按星期的报价/交易时段时间表是 MQL5 专有接口，Python 包取不到，v1 不提供，接口文档注明缺失；不伪造数据，将来确需时借 EA 桥补。
2. **行情**：任意品种的实时报价（bid/ask/last + 时间戳）、历史 K 线（全部标准周期）、历史 tick，全部**同步按需拉取**——每次调用直接穿透到终端取其最新值，不做后台轮询、不缓存。"新 tick 到就动"这类事件驱动需求属于策略段：策略侧自己按节奏调用，或届时加订阅层（接口不堵死）。
3. **账户**：余额、净值、可用保证金、杠杆、保证金模式、持仓明细、挂单、历史委托、历史成交、券商/服务器信息。
4. **交易**：市价开仓、挂单、改单（SL/TP/价格）、平仓（全部/部分）；每次返回完整结果（retcode、成交价、滑点、手续费、comment），成功失败都如实上报。**实盘保险丝（硬性运行时守卫）**：每次交易调用前校验账户类型，非模拟盘一律拒绝下单（冒烟脚本同样受管）；唯一解锁方式是配置文件里显式开启实盘，默认关闭。

另外两项网关自身职责：

5. **连接管理**：初始化并绑定终端、断线检测与自动重连（终端重启或重新登录后能自行恢复）。
6. **验收冒烟脚本**：一条命令跑完整链路——拉全品种列表 → 抽样若干品种拉实时报价与历史 K 线/tick → 拉一次完整账户快照 → 在模拟盘真实开一单并平掉，打印每步结果。

## 非目标（基石阶段不做）

- 策略、信号、指标计算、回测（策略段的事）
- 本地历史数据库 / 行情落盘存储（做回测时再设计）
- 跨机器部署、EA 桥、多终端并行（接口不堵死，但不实现）
- 图形界面、监控面板、Web 服务
- 高频场景优化（毫秒以下反应）

## 反目标（做了就算失败）

- 网关内出现任何策略性判断（包括"顺手"帮策略加移动止损这类）
- 在实盘账户上执行任何测试单——一切真实下单只发生在模拟盘；动实盘必须用户明确下令
- 静默吞掉交易失败或数据缺失（错误必须原样上报给调用方）

## 约束与环境（2026-10-22 实测）

- Windows 机器（RDP 会话内）；MT5 终端已安装且正在运行：`C:\Program Files\MetaTrader 5\terminal64.exe`，当前登录**模拟盘**。
- 终端必须保持运行并登录，网关才有数据可取——产品级约束，写进使用说明。
- 本机**尚未安装 Python**（仅有微软商店占位符）。施工第一步：安装 64 位 Python（3.11–3.13，以 MetaTrader5 包有对应 wheel 为准）+ venv + `pip install MetaTrader5`。
- MetaTrader5 包为同步调用且非线程安全：网关内部须串行化所有对它的调用（如全局锁），对上层呈现线程安全接口。
- 无推送模型：Python 包不推送行情；基石的契约是"调用即取终端最新值"（见目标 2）。
- 部分品种需 `symbol_select` 加入 Market Watch 后才能复制行情——网关内部处理，不暴露给上层。

## 已定决策

用户定：

- 用官方 MetaTrader5 Python 包，不自写 EA 桥（保留以后更换的可能）
- 系统语言 Python；以后换/加语言须先与用户商量
- 模拟盘可真实下单测试；实盘不许碰

我定（可推翻）：

- 网关形态为**库**（进程内 import），不做独立服务——策略也是 Python；接口不绑死进程模型，以后可包成服务
- 按需取数不落库；行情为同步穿透取值，不做后台轮询/订阅（策略需要时再加）
- 实盘硬守卫：非模拟盘拒绝一切交易，唯一解锁方式为配置文件显式开启，默认关闭
- 品种目录不提供按星期的时段表（Python 包取不到），注明缺失而不伪造
- 项目建在当前工作区
- Python 依赖走 venv，不污染系统环境
